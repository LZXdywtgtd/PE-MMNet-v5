feat(loss): V5A3 覆盖距离 loss（Catmull-Rom 样条 + Hausdorff + 组合）

[背景]
v5-α 主损失函数。架构设计 §3.5：覆盖距离 + bbox + GP + 泊松四项加权。
前序 V5A2 已实现 SplineHead 输出 8-16 动态关键点，本任务实现其监督信号。
训练循环需要这个 loss 才能 backprop 到输出头（V5A4/A5 依赖）。

[实现]
1. catmull_rom_spline_torch(points, num_samples) — 纯 PyTorch 三次样条
   - 端点镜像延拓 ghost points（保持 C¹ 连续）
   - K=2 退化为线性插值
   - 完全可微（对控制点求梯度无障碍）

2. coverage_loss(pred_kpts, true_pixels, M, mode)
   - mode="chamfer"（默认，mean_i min_j d，训练更稳）
   - mode="hausdorff"（max_i min_j d，评估更严）

3. poisson_prior(pred_kpts) — 段长方差最小化（鼓励等弧长分布）

4. OrderedKeypointLoss — 组合 loss
   - λ_cov=1.0, λ_bbox=1.0, λ_gp=0.1, λ_poisson=0.05
   - bbox: Smooth L1
   - gp: GPModule.log_marginal_likelihood（可选）
   - 返回 dict: {total, coverage, bbox, gp, poisson}

[为何选 Catmull-Rom 而非 scipy CubicSpline]
- scipy 不可微（基于 numpy，无 autograd 通路）
- Catmull-Rom 是 Hermite 三次样条（C¹），纯 PyTorch 实现
- 用户文档"三次 B 样条"即指此（标准等价术语）
