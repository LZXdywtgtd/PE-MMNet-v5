## 二、数据准备

### v5-α **不需要真实数据**

```
❌ 无需数据目录
❌ 无需 GT 标注
❌ 无需 crack_annotator（v5-β 才用）
```

`PatchSimulator.simulate(seed=N)` 每次生成一个独立的 256×256 patch 样本：

| 字段 | 形状 | 说明 |
|------|------|------|
| `temperature_field` | (T, 256, 256) | 温度场历史 |
| `stress_field` | (T, 256, 256) | 应力场历史 |
| `heatmap` | (256, 256) | 最终温度场（归一化到 [0,1]）|
| `crack_mask` | (256, 256) uint8 | 像素级裂纹 mask（GT）|
| `crack_keypoints` | (K, 2), K∈[8,16] | 关键点 GT |
| `crack_bbox` | (4,) | bbox GT |

### v5-β 真实数据接入

v5-β 启动后接入真实数据时，仅需替换 `data/patch_dataset_v5.py`，**trainer 接口不变**。

## 四、模型变体选择

| 变体 key | 架构 | 显存（256 patch） | 推荐场景 |
|----------|------|------|----------|
| `resnet18` | ResNet-18 + Cross-Attention + SplineHead + GP | ~2 GB | 新手首选，快速验证 |
| `swin_yolo` | Swin-Tiny + YOLO-FPN + SplineHead + GP | ~4 GB | 空间定位精度 |
| `vit_yolo` | ViT-Small + YOLO-FPN + SplineHead + GP | ~4 GB | 全局注意力 |
| `swin_yolo_patchtst` | Swin-Tiny + YOLO-FPN + PatchTST + SplineHead + GP | ~6 GB | 长程时序依赖 |
| `detr` | ResNet-18 + Transformer Encoder-Decoder + SplineHead + GP | ~5 GB | 全局上下文 |

5 个变体都在 `run_train_v5.py` 的 `--variant` choices 中。详细架构见 [docs/v5_架构设计.md](v5_架构设计.md) §2.1。

## 五、高级参数

### 5.1 GP 模块开关

```bash
# 启用 GP（默认）
python run_train_v5.py --variant resnet18 --epochs 150

# 禁用 GP（消融实验）
python run_train_v5.py --variant resnet18 --no_gp --epochs 150
```

### 5.2 ImageNet 预训练

```bash
python run_train_v5.py --variant swin_yolo --pretrained_2d --epochs 150
```

> 启用 `--pretrained_2d` 后 2D 骨干加载 ImageNet 权重，并冻结（V5-B002）。

### 5.3 关键点范围

```bash
# 缩小范围（更稀疏）
python run_train_v5.py --variant resnet18 --min_kpts 6 --max_kpts 10

# 扩大范围（更密集）
python run_train_v5.py --variant resnet18 --min_kpts 12 --max_kpts 24
```

### 5.4 覆盖距离模式

```bash
# Chamfer 距离（默认，双向平均）
python run_train_v5.py --variant resnet18 --coverage_mode chamfer

# Hausdorff 距离（最大最小距离，对离群点敏感）
python run_train_v5.py --variant resnet18 --coverage_mode hausdorff
```

### 5.5 损失权重

```bash
python run_train_v5.py --variant resnet18 \
    --lambda_coverage 1.0 \
    --lambda_bbox 1.0 \
    --lambda_gp 0.1 \
    --lambda_poisson 0.05
```

### 5.6 数据增强

```bash
# 启用增强（默认：hflip + vflip + rot90 + Gaussian noise）
python run_train_v5.py --variant resnet18 --epochs 150

# 禁用增强（消融实验）
python run_train_v5.py --variant resnet18 --no_aug --epochs 150
```

### 5.7 调试模式（fast_thermal）

```bash
# 用 1 min 短周期（仅冒烟测试用，物理失真）
python run_train_v5.py --variant resnet18 --fast_thermal --epochs 2
```

> ⚠️ `--fast_thermal` 仅用于冒烟测试。生产训练必须用默认 11.7h 周期（V5-017）。

### 5.8 热曲线自定义

通过 `config.json` 或 `thermal_profile` 参数修改：

```json
{
  "_v5_specific": {
    "thermal_profile": {
      "ramp_up_c_per_min": 5.0,
      "soak_temp_c": 1280.0,
      "soak_duration_min": 30,
      "cool_down_c_per_min": 3.0
    }
  }
}
```

## 六、显存配置

v5-α `TrainerV5` 默认 `patch_size=256`，`batch_size=4`。显存不足时调整：

| 空闲显存 | patch_size | batch_size | 推荐变体 |
|----------|-----------|-----------|---------|
| ≥12 GB | 256 | 4-8 | 全 5 变体 |
| 6-12 GB | 256 | 2-4 | 全部（patchtst 限 batch=2）|
| 4-6 GB | 128 | 4 | 全部 |
| <4 GB | 64 | 2 | 全部（仅冒烟）|

**手动指定**：

```bash
python run_train_v5.py --variant resnet18 --patch_size 128 --batch_size 8
```

## 七、常见问题

| 问题 | 解决方案 |
|------|----------|
| `CUDA: False` | 见 [CUDA 安装指南](CUDA安装指南.md) §六 |
| 显存不足 | `--batch_size 2 --patch_size 128` |
| 预训练权重下载慢 | 设 `HF_ENDPOINT=https://hf-mirror.com` |
| 仿真预计算太慢 | `--n_samples 100` + `--fast_thermal`（仅冒烟） |
| Loss = NaN | `--lr 1e-4`（已是默认）；空真值像素已用 surrogate 处理（V5-018）|
| 续训从 epoch 0 开始 | 确认 `load_checkpoint` 加载了 RNG 状态（详见 v5_架构设计.md §5.5）|

### 7.1 预训练权重问题（swin_yolo / vit_yolo / detr / patchtst）

这些变体需要从 HuggingFace 下载预训练权重。

**方法 1：设置镜像站（推荐）**

```bash
# Windows
set HF_ENDPOINT=https://hf-mirror.com

# Linux/Mac
export HF_ENDPOINT=https://hf-mirror.com
```

**方法 2：使用 resnet18 变体（无需预训练权重）**

```bash
python run_train_v5.py --variant resnet18 --epochs 2
```
