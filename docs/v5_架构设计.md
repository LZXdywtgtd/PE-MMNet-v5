## 2. 各模块职责

### 2.1 Backbone（5 变体保留）

| 变体 | 来源文件 | 说明 |
|---|---|---|
| resnet18 | `models/pe_tsnet_multimodal_v5.py` | v4 backbone 沿用 |
| swin_yolo | `models/pe_tsnet_yolo_v5.py` | Swin-Tiny + YOLO-FPN |
| vit_yolo | `models/pe_tsnet_yolo_v5.py` | ViT-Small + YOLO-FPN |
| detr | `models/pe_tsnet_detr_v5.py` | ResNet-18 + Transformer |
| swin_yolo_patchtst | `models/pe_tsnet_patchtst_v5.py` | PatchTST 时序 |

**v5-α 改动**：所有变体的最后输出层（output_head）替换为 Spline 输出头。

### 2.2 Cross-Attention Fusion（沿用 v4）

位于 `models/pe_tsnet_multimodal_v5.py` 的 `CrossAttentionFusion` / `GatedMultimodalFusion`：
- v4 已实现，v5-α 直接沿用
- 输入：3 路 backbone 特征
- 输出：融合后的特征张量

### 2.3 GP 嵌入模块（v5 新增）

位于 `models/gp_module.py`：
- **作用**：将物理约束以高斯过程先验的形式嵌入数据流
- **接口**：接收融合特征，输出经过 GP 调制后的特征
- **是否默认启用**：默认 True（消融实验可关闭）

设计要点：
- 高斯核函数：`k(x, x') = σ² exp(-||x - x'||² / (2ℓ²))`
- 长度尺度 ℓ 与方差 σ² 设为可学习参数
- 调制方式：`output = input + GP_residual(input)`

### 2.4 Spline 输出头（v5 新增）

位于 `models/spline_head.py`：
- **输入**：GP 调制后的特征 (B, hidden_dim)
- **输出**：
  - bbox: (B, 4) — 归一化角点
  - keypoints: (B, K, 2) — K ∈ [8, 16] 的有序关键点
- **K 选择**：由模型自适应决定（端点 + 等弧长采样）

设计要点：
- bbox 回归：`MLP → (B, 4)` + sigmoid 归一化
- 关键点生成：
  1. 先回归 K 个"骨架点"（锚点）
  2. 用三次 B 样条拟合锚点 → 平滑曲线
  3. 在曲线上等弧长采样 8–16 个点作为最终输出

## 3. 损失函数

### 3.1 主损失：B 样条 + Hausdorff 覆盖距离

位于 `training/ordered_kp_loss.py`：

```python
def coverage_loss(pred_kpts, true_crack_pixels):
    """
    pred_kpts: (B, K, 2) - 预测的关键点
    true_crack_pixels: (B, N, 2) - 真值裂纹像素
    """
    # 1. 拟合 B 样条
    splines = fit_cubic_splines(pred_kpts)  # 每样本一条曲线
    
    # 2. 在曲线上密集采样
    spline_samples = sample_along_splines(splines, M=200)  # (B, M, 2)
    
    # 3. 真值像素到曲线的最小距离
    dist = cdist(true_crack_pixels, spline_samples)  # (B, N, M)
    d_true_to_spline = dist.min(dim=-1).values  # (B, N)
    
    # 4. Hausdorff 距离（最大距离）
    return d_true_to_spline.max(dim=-1).values.mean()
```

### 3.2 bbox 损失

```python
bbox_loss = SmoothL1Loss(pred_bbox, true_bbox)
```

### 3.3 GP 模块损失

```python
gp_reg = -gp_module.log_marginal_likelihood()  # GP 超参数正则
```

### 3.4 泊松先验

```python
poisson_reg = -PoissonLogLikelihood(pred_kpts, expected_density)
```

### 3.5 总损失

```python
total = (
    1.0  * coverage_loss
    + 1.0  * bbox_loss
    + 0.1  * gp_reg
    + 0.05 * poisson_reg
)
```

## 4. 数据流

### 4.1 训练数据（仿真生成）

```
patch 仿真器 (data/patch_simulator_v5.py)
   ↓
   输出：
   - temperature_field: (1, 256, 256)
   - stress_field:      (1, 256, 256)
   - heatmap:           (1, 256, 256)
   - crack_mask:        (1, 256, 256)  ← 像素级 GT
   - crack_kpts:        (K, 2)         ← 关键点 GT（K ∈ [8,16]）
   - crack_bbox:        (4,)           ← bbox GT
   ↓
torch Dataset (data/dataset_multimodal_v5.py)
   ↓
DataLoader → 模型训练
```

### 4.2 推理数据

v5-α 不部署（无真实数据）。v5-β 部署时：

```
真实 patch → 仿真器预测 OR 直接烧前快照
   ↓
模型推理 → 输出 (bbox + 关键点)
   ↓
B 样条拟合 → 平滑裂纹轨迹
   ↓
可视化 / GT 比对
```

## 6. 与 v4 的关键差异

| 维度 | v4 | v5-α |
|---|---|---|
| **输出格式** | 6 维向量 / 二值掩膜 | bbox + 动态关键点 |
| **输出头** | Linear / MaskDecoder | Spline 输出头 |
| **物理约束** | 单调性损失 | GP 嵌入模块 + 泊松先验 |
| **损失核心** | MSE + Dice | Hausdorff 覆盖距离 |
| **数据格式** | 检测框 / 掩膜 | 像素级裂纹 mask + 关键点 |
