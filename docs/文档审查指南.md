## 三、通用审查维度

### 3.1 准确性审查（最重要）

**核心原则**：文档必须与实际代码一致。

#### 必查项

| 检查项 | 审查方法 |
|--------|----------|
| CLI 参数是否存在 | `grep -n "add_argument" run_train_v5.py` |
| 函数签名是否正确 | `python -c "import inspect; from training.trainer_v5 import TrainerV5; print(inspect.signature(TrainerV5))"` |
| 默认参数值是否正确 | 检查源代码中的默认值 |
| 函数/类名是否正确 | 对照 `models/`, `training/` 源文件 |
| 损失权重默认值是否正确 | 检查 `training/ordered_kp_loss.py` 中的默认值 |
| 硬件要求/显存占用是否合理 | 对照代码中的显存检测逻辑 |

#### 验证命令

```bash
# 验证参数存在
```

### 3.3 一致性审查

#### 跨文档一致性

同一信息在多个文档中出现时，必须保持一致：

| 必查一致性项 | 涉及文档 |
|------------|----------|
| 默认学习率 | 快速配置指南、调参指南、开发人员文档 |
| 模型显存占用 | 架构设计文档、快速配置指南 |
| 模型输入尺寸 | v5_架构设计.md、快速配置指南 |
| 任务 ID 命名 | 团队协作指南（占位）、开发人员文档、CHANGELOG |
| 损失函数默认值 | v5_架构设计.md、调参指南 |

#### 跨文档一致性脚本

```python
import os, re
keywords = ['1e-4', '256', 'min_kpts=8', 'max_kpts=16', 'use_gp=True']
for root, _, files in os.walk('docs'):
    for f in files:
        if f.endswith('.md'):
            path = os.path.join(root, f)
            with open(path, 'r', encoding='utf-8') as fp:
                content = fp.read()
            for kw in keywords:
                if re.search(kw, content):
                    for ln, line in enumerate(content.splitlines(), 1):
                        if re.search(kw, line):
                            print(f'{path}:{ln}: {line.strip()[:120]}')
```

## 五、审查流程

### Step 1：代码审查

修改代码后，先确认需要更新的文档：

1. 新增/修改了 CLI 参数 → 更新 `快速配置指南.md`、`调参与算法工程指导文档.md`、`开发人员文档.md`
2. 新增/修改了模型架构 → 更新 `v5_架构设计.md`
3. 新增/修改了损失函数 → 更新 `v5_架构设计.md`、`调参与算法工程指导文档.md`
4. 新增/修改了公开函数 → 更新 `api.md`

### Step 2：文档自检

按照本指南 §三 通用审查维度逐项检查。

### Step 3：交叉引用验证

```python
import os, re
for root, _, files in os.walk('docs'):
    for f in files:
        if f.endswith('.md'):
            path = os.path.join(root, f)
            with open(path, 'r', encoding='utf-8') as fp:
                content = fp.read()
            for link in re.findall(r'\]\(([^)]+\.md)\)', content):
                base = os.path.dirname(path)
                target = os.path.normpath(os.path.join(base, link))
                if not os.path.exists(target):
                    print(f'BROKEN: {path} -> {link}')
```
