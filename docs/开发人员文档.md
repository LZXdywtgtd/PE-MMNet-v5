## §0. v5-α 概览（30 秒）

PE-MMNet v5-α 是 v4.6.11 的**算法重写分支**：

| 维度 | v4 | v5-α |
|---|---|---|
| **输入** | 2 通道（温度场 + 应力场） | **3 通道**（温度场 + 应力场 + 热力图）|
| **输出** | 6 维向量 / 二值掩膜 | **bbox (4-dim) + 8–16 动态关键点** |
| **输出头** | Linear / MaskDecoder | **SplineHead + GP 嵌入** |
| **损失** | MSE + Dice + 单调性 | **Catmull-Rom 样条 + Hausdorff + GP LML + 泊松** |
| **数据** | 真实实验数据 | **仿真自包含**（PatchSimulator）|

**v5-α 完整工作流**：

```
PatchSimulator.simulate(seed=N)
    ↓ dict（temperature/stress/heatmap/crack_mask/keypoints/bbox）
PatchDatasetV5.__init__
    ↓ 一次性仿真所有样本到内存
DataLoader + collate_v5
    ↓ 变长 padding
TrainerV5._train_step
    ↓ forward → {bbox, keypoints, validity, K, gp_lml}
OrderedKeypointLoss
    ↓ coverage + bbox + gp + poisson
optimizer.step()
    ↓
CSVHistory.log() + save_checkpoint(best/latest)
```

## §2. 添加新模型变体

### 2.1 复用现有骨架

v5-α 5 变体共享相同接口：

```python
def forward(self, x_1d: Tensor, x_2d: Tensor) -> dict:
    return {
        "bbox":      Tensor,    # (B, 4)
        "keypoints": Tensor,    # (B, max_kpts, 2)
        "validity":  Tensor,    # (B, max_kpts) bool
        "K":         Tensor,    # (B,) int
        "gp_lml":    Tensor | None,  # scalar（仅 use_gp=True）
    }
```

### 2.2 完整流程

1. **新建模型文件** `models/pe_tsnet_<new>_v5.py`

2. **继承 5 变体共同基约定**：

   ```python
   class MyNewVariantV5(nn.Module):
       def __init__(self, image_channels=3, use_gp=True, min_kpts=8, max_kpts=16, **kwargs):
           super().__init__()
           self.backbone_2d = ...   # 复用 v4 骨干
           self.fusion = ...        # CrossAttentionFusion / GatedMultimodalFusion
           self.gp = GPModule(in_dim, out_dim) if use_gp else None
           self.head = SplineHead(in_dim, min_kpts, max_kpts)

       def forward(self, x_1d, x_2d):
           feat = self.backbone_2d(x_2d)
           feat = self.fusion(feat)
           if self.gp is not None:
               feat, gp_lml = self.gp(feat)
           else:
               gp_lml = None
           return self.head(feat, gp_lml=gp_lml)
   ```

3. **注册到工厂**：

   ```python
   # models/__init__.py
   from .pe_tsnet_<new>_v5 import MyNewVariantV5

   V5_MODEL_REGISTRY["my_new_variant"] = lambda **kw: MyNewVariantV5(**kw)
   ```

4. **添加 CLI 选项**：

   ```python
   # run_train_v5.py
   parser.add_argument(
       "--variant", ...,
       choices=["resnet18", "swin_yolo", "vit_yolo", "detr",
                "swin_yolo_patchtst", "my_new_variant"],
   )
   ```

5. **写单元测试**（参考 `tests/test_pe_tsnet_v5.py` 的 5 变体 e2e 测试）。

### 2.3 检查点兼容性

新变体的 state_dict 必须与旧变体**互不兼容**。恢复时 `load_checkpoint` 会做 strict matching，shape 不对会抛错。

## §3. 添加新损失分量

### 3.1 现有损失（V5A3）

```python
total = lambda_coverage * coverage_loss \
      + lambda_bbox     * bbox_loss \
      + lambda_gp       * gp_lml \
      + lambda_poisson  * poisson_prior
```

### 3.2 添加新损失（例如：方向一致性）

1. **实现损失函数**（在 `training/ordered_kp_loss.py` 内）：

   ```python
   def direction_consistency_loss(pred_kpts, true_kpts, kpt_mask):
       """预测关键点方向序列应与真值方向序列一致"""
       # ... torch.autograd 友好的实现
       return loss_value
   ```

2. **接入 `OrderedKeypointLoss.forward`**：

   ```python
   def forward(self, pred_bbox, pred_kpts, kpt_validity, true_bbox,
               true_crack_pixels, pixel_mask=None):
       # ... 原有 4 项 loss
       new_loss = direction_consistency_loss(pred_kpts, true_crack_pixels, ...)
       total = total + self.lambda_direction * new_loss
       return {
           "total": total,
           "coverage": cov, "bbox": bbox_l,
           "gp": gp, "poisson": pois, "direction": new_loss,
       }
   ```

3. **TrainerV5 调用方**（`training/trainer_v5.py`）：把 `loss_dict` 的 keys 写入 CSV 列。

4. **加 CLI 参数 + 加测试**。

### 4.1 检查点格式

```python
        "torch_cuda": torch.ByteTensor (cuda),
    },
    "extra":                 dict | None,
}
```

### 4.2 保存

```python
from training.trainer_v5 import save_checkpoint

save_checkpoint(
    path="checkpoints/v5a6_resnet18/best.pt",
    model=trainer.model,
    optimizer=trainer.optimizer,
    epoch=42,
    best_val_loss=0.2583,

```

### 4.3 加载 + 续训

```python
# 方式 A：完整续训（推荐）
trainer = TrainerV5(...)
trainer.fit(resume_from="checkpoints/v5a6_resnet18/latest.pt")

# 方式 B：手动加载
from training.trainer_v5 import load_checkpoint
state = load_checkpoint("checkpoints/.../latest.pt", model=model, optimizer=optim, device="cuda")
# state["epoch"], state["best_val_loss"] 可读
```

### 4.4 续训关键：RNG 状态恢复

`load_checkpoint` 会恢复 `python / numpy / torch` 3 种 RNG。续训可完全复现（含 dropout、batch shuffle、噪声增强）。

**手动复现测试**：

```python

a = torch.rand(5)
set_seed(42)
b = torch.rand(5)
assert torch.allclose(a, b)  # 通过
```

## §5. 调试技巧

### 5.1 仿真卡顿？

每个 256×256 样本 ~22.5s（fast_thermal），100 样本 = ~37 min。调试时：

```bash
# 缩小样本数 + 用 fast_thermal
python run_train_v5.py --n_samples 4 --patch_size 64 --fast_thermal --epochs 1
```

> ⚠️ patch=64 + 阈值 50 MPa 通常**没有裂纹**（峰值拉应力 < 阈值）。调试损失时降到 `--crack_stress_threshold_MPa 5.0`。

### 5.2 Loss = NaN？

- 检查 `OrderedKeypointLoss.coverage_loss`：当 `true_crack_pixels.size(1)=0` 已用 surrogate 返回（V5-018）
- 检查 `SplineHead`：bbox sigmoid 后值域 [0,1]，关键点 bbox 内 clamp
- GPU NaN 检查：`torch.autograd.set_detect_anomaly(True)`

### 5.3 显存不足？

| 变体 | 256 patch @ batch=4 显存 |
|------|------|
| resnet18 | ~2 GB |
| swin_yolo / vit_yolo | ~4 GB |
| detr | ~5 GB |
| swin_yolo_patchtst | ~6 GB |

降到 `batch_size=2 --patch_size=128` 一般可跑。

### 5.4 仿真预计算太慢？

`PatchDatasetV5.__init__` 时一次性仿真所有样本。

- 调小 `n_samples`
- 用 `--fast_thermal`（仅冒烟）
- v5-β 真实数据接入后改磁盘缓存（接口不变）

### 5.5 续训 epoch 接不上？

`load_checkpoint` 会自动恢复 RNG 状态。如果 loss 曲线从 epoch 0 重新画：

- 检查 `fit(resume_from=...)` 是否传入正确路径
- 检查 checkpoint 的 `epoch` 字段值

### 5.6 数据路径冲突？

v5-α **不读 `data_root`**——`PatchSimulator.simulate()` 完全自包含。

## §7. 代码规范

### 7.1 命名

- 类：`PascalCase`（`PatchSimulator`, `OrderedKeypointLoss`）
- 函数/变量：`snake_case`（`train_model`, `best_loss`）
- 常量：`UPPER_SNAKE`（`V5_MODEL_REGISTRY`, `FAST_PROFILE`）
- 私有函数：`_leading_underscore`（`_safe_mkdtemp`, `_resolve_task_id`）

### 7.2 模型风格

- `Linear` + `LayerNorm` + `SiLU` + `Dropout`
- 优化器：`Adam` + `CosineAnnealingLR` + 梯度裁剪 `max_norm=1.0`
- 保护机制：NaN 守卫 + `torch.autograd.set_detect_anomaly(True)`（开发模式）

### 7.3 训练/推理模式

- 训练：`model.training=True` → 返回原始预测
- 推理：`model.training=False` → 返回最优预测（动态 K 调整）
- 不要在 `forward` 内部改 `.train()` / `.eval()`

### 7.4 工具脚本存放规范

- `tools/` 下的脚本**独立可运行**（`python tools/foo.py`）
- 用 `argparse` 接收参数，**不 import 项目内部模块**（除非必要）
- 输出路径用 `Path(__file__).resolve().parent.parent` 推导项目根
