# 项目算法与训练实验设计报告

> PE-MMNet v5 系列（α + β）多模态裂纹预测系统
> 版本：5.0.5-alpha | 更新：2026-08-24
>
> **继承说明**：本文件由 v4.6.11 同名文档**完全重写**。v5-α 算法与实验设计与 v4 完全不同：
> - v4 任务：6 维向量回归（位置位置 / 位置尺寸 / 置信度 / 密度）
> - v5-α 任务：bbox + 8–16 动态有序关键点
> - v5-β 任务：v5-α + UV 逆映射 + 位置 6D pose + 多视图融合
> - v4 损失：MSE + Dice + 单调性
> - v5-α 损失：Catmull-Rom 样条 + Hausdorff + GP LML + 泊松先验
> - v5-β 损失：v5-α + 3D 重投影 + 位置 6D 回归
> - v4 数据：真实实验数据
> - v5-α 数据：仿真自包含（PatchSimulator）
> - v5-β 数据：真实 3D 烧后图 + UV 映射 + 多机位

---

## 一、问题背景

日用陶瓷在热震过程中会产生裂纹，需要：
1. 预测裂纹的**空间位置**（bbox）
2. 预测裂纹的**轨迹**（8–16 动态有序关键点）
3. 预测结果应**物理可解释**（温度场 → 应力集中 → 裂纹萌生 → 扩展）

v5-α 的核心改进：在 v4 的多模态融合基础上，引入**物理先验**（GP 嵌入模块 + 泊松过程），让模型学习"为什么这里有裂纹"而非仅"这里有裂纹"。

---

## 二、v5-α vs v4 算法对比

| 维度 | v4 | v5-α |
|---|---|---|
| **输入模态** | 温度时序 + 温度场 + 应力场（2 通道 2D）| **3 通道 2D**（温度场 + 应力场 + 热力图）|
| **空间维度** | 1cm × 1cm 平面 | **256×256 patch**（任意形状无关）|
| **输出格式** | 6 维向量（x, y, l, w, conf, density）| **bbox + 8–16 动态关键点** |
| **输出头** | Linear + YOLO grid + DETR queries | **SplineHead + GP 嵌入** |
| **骨干** | 5 变体（resnet18 / swin_yolo / vit_yolo / detr / patchtst） | **同 5 变体（沿用骨干，仅换输出头）** |
| **物理约束** | 单调性损失（启发式）| **GP 嵌入模块 + GP LML 正则** |
| **损失核心** | MSE + Dice + 单调性 | **Catmull-Rom 样条 + Hausdorff + GP + 泊松** |
| **数据** | 真实烧制实验数据 | **仿真自包含**（PatchSimulator）|

## 三、v5-α 算法原理

### 3.1 输入表示

每个 256×256 patch 包含 3 通道：

| 通道 | 物理含义 | 来源 |
|---|---|---|
| 温度场 | 烧制过程中的空间温度分布 | PatchSimulator（FDM 求解热传导方程）|
| 应力场 | 热应力 + 粘弹性松弛的应力分布 | PatchSimulator（Maxwell 粘弹性）|
| 热力图 | 最终温度场（归一化到 [0,1]）| PatchSimulator 输出 |

### 3.2 模型架构

```
输入 (B, 3, 256, 256) + (B, 300)
    ↓
2D 骨干（5 变体之一）
    ↓
Cross-Attention Fusion（v4 沿用）
    ↓
GP 嵌入模块（v5 新增）
    ↓
Spline 输出头（v5 新增）
    ↓
{bbox (B,4), keypoints (B,K,2), validity (B,K), K (B,)}
```

### 3.3 Spline 输出头

**核心思想**：关键点是有序的（沿裂纹轨迹），不应该用独立回归。

1. 骨干特征 → MLP → K 个"骨架点"（锚点）
2. 用三次 B 样条拟合锚点 → 平滑曲线
3. 在曲线上等弧长采样 8–16 个点作为最终输出

**优势**：
- 输出点数自适应（短裂纹 8 个，长裂纹 16 个）
- 关键点天然有序
- B 样条保证平滑性

### 3.4 GP 嵌入模块

**核心思想**：物理约束（温度梯度→应力集中→裂纹萌生）以高斯过程先验形式嵌入数据流。

**实现**：
- 高斯核函数：`k(x, x') = σ² exp(-||x-x'||² / (2ℓ²))`
- 长度尺度 ℓ 与方差 σ² 设为可学习参数
- 调制方式：`output = input + GP_residual(input)`
- L2 row-normalize by `sqrt(in_dim)` 后再算 kernel（V5-014/015 记录）

**正则**：GP 的 log marginal likelihood 作为损失分量。

### 3.5 覆盖距离 loss

**算法**：

1. 预测关键点 → Catmull-Rom 样条拟合
2. 在曲线上等弧长采样 M=200 个点
3. 真值裂纹像素 → 找每个像素到曲线的最小距离
4. **Chamfer** 模式：双向平均
5. **Hausdorff** 模式：取最大最小距离

**为什么用 Catmull-Rom 而不是三次 B 样条**：
- Catmull-Rom 是插值样条（曲线必须经过控制点），适合小 K
- B 样条是逼近样条（曲线在控制点附近），适合大 K
- v5-α 默认 K=8-16，Catmull-Rom 更合适
- Catmull-Rom 可纯 PyTorch 实现（scipy 不 autograd）

## 四、仿真器（PatchSimulator）

详见 [docs/v5_仿真升级清单.md](v5_仿真升级清单.md)。核心：

| 升级项 | v5-α 实现 | 物理依据 |
|---|---|---|
| S1 多方向热交换 | FDM 显式 Euler，2D 拉普拉斯 | Fourier 热传导定律 |
| S2 表面辐射 | Stefan-Boltzmann：q = εσ(T⁴-T_env⁴) | 黑体辐射 |
| S3 应力松弛 | Maxwell 粘弹性：σ + τ σ̇ = E ε | Maxwell 模型 |
| S4 三段曲线 | 升温(240min) + 保温(30min) + 降温(400min) | 真实烧制周期 |
| S5 裂纹萌生 | **简化版**（应力阈值），Griffith 留 v5-β | 简化判据 |
| S6 裂纹扩展 | **简化版**（最长连通域），LEFM 留 v5-β | 简化判据 |
| S7 像素级 mask | 骨架化 + 最长连通域 + 等弧长采样 | 数字图像处理 |

## 五、训练设计

### 5.1 损失函数

```python
total = λ_cov * coverage + λ_bbox * bbox_smooth_l1 + λ_gp * gp_lml + λ_poisson * poisson
```

### 5.2 优化器与调度

- 优化器：`Adam` (lr=1e-4)
- 调度：`CosineAnnealingLR`
- 梯度裁剪：`max_norm=1.0`

### 5.3 训练循环

详见 [docs/v5_架构设计.md §5](v5_架构设计.md)。

### 5.4 评估指标

| 指标 | 说明 |
|------|------|
| **物理对齐度** | 裂纹萌生点 vs Griffith 应力集中点 |
| **物理覆盖率** | 预测轨迹落在 crack_mask 95% 内 |
| **覆盖距离** | Chamfer / Hausdorff |
| **关键点 MAE** | 关键点位置误差 |
| **bbox IoU** | bbox 交并比 |

> ⚠️ v5-α 与 v4 输出格式不同，**R²/RMSE/违反率** 不适用。

## 六、实验设计（V5A6）

### 6.1 主实验

- **5 变体 × 150 epoch × 默认 11.7h 周期**
- 每个变体独立训练 + 独立评估
- 输出：`logs/training_history/V5A*.csv` + `benchmark_results/v5_comparison.md`

### 6.2 消融实验

| 实验 | 配置 | 目的 |
|---|---|---|
| A1 基线 | use_gp=True, use_aug=True, coverage=chamfer | 完整配置 |
| A2 消融 GP | use_gp=False | GP 模块的贡献 |
| A3 消融增强 | use_aug=False | 数据增强的贡献 |
| A4 改 Hausdorff | coverage_mode=hausdorff | 距离度量的影响 |

### 6.3 物理因果链展示（导师专项）

按用户 2026-08-24 反馈："**AI 学习需要我们能推得出来**"，需额外产出：

- 1 个变体（推荐 resnet18）跑 5 epoch
- 输出 4 张图：温度场 → 应力场 → 裂纹 mask → 关键点轨迹
- 证明：模型学习的是物理链条，不是黑箱

详见 `tools/patch_simulator_visualizer.visualize_patch()`。

v5-α 算法验证成功后，v5-β 启动：

| 项 | v5-α | v5-β |
|---|---|---|
| 数据 | 仿真 patch | 真实烧制（crack_annotator）|
| 3D | 不支持 | UV 展开 + 真实 3D 物体 |
| 位置图像 | L3 默认关闭 | L0-L4 完整管线 |
| 数据缓存 | 内存 | 磁盘 hdf5/npz |
| 团队协作 | 单任务 | team_train_v5 + Streamlit |

### 8.1 v5-β 详细实验设计

#### 8.1.1 主实验

- **5 变体 × 150 epoch × 真实数据集**
- 每个变体独立训练 + 独立评估
- 输出：`logs/training_history/V5B*.csv` + `benchmark_results/v5_b_comparison.md`

#### 8.1.2 真实数据采集设计

| 数据集 | 数量 | 用途 | 标注方式 |
|---|---|---|---|
| Train | 5000+ | 训练集 | crack_annotator |
| Val | 500 | 验证集（早停 + 超参）| crack_annotator |
| Test | 500 | 测试集（最终评估）| crack_annotator + 多人一致性检查 |
| Cross-material | 1000 | 材料泛化测试（4 类陶瓷）| crack_annotator |

#### 8.1.3 消融实验（v5-β）

| 实验 ID | use_gp | use_position_image | use_uv_inverse | 改进点 |
|---------|--------|--------------------|----------------|----------|
| B1 基线 | True | True | True | 完整配置 |
| B2 消融 GP | False | True | True | GP 模块的贡献 |
| B3 消融位置 | True | False | True | 位置图像的贡献 |
| B4 消融 UV | True | True | False | UV 映射的贡献 |
| B5 改进 GP | True (running stats) | True | True | 修复 V5-014/015 |
| B6 完整 Griffith | True (新仿真) | True | True | S5 完整版 |

#### 8.1.4 物理因果链展示（v5-β 导师专项）

- 真实烧后图 + UV 映射 + 模型预测 + 3D 反投影
- 4 视角展示：
  1. 真实烧后 RGB
  2. UV 展开 patch（输入）
  3. 模型预测（关键点 + bbox）
  4. UV 逆映射回 3D 表面（红色轨迹）
- 证明：模型学到了"3D 形状 → 2D patch → 轨迹预测"的物理链条

### 8.2 v5-β 评估指标

| 指标 | 计算方式 | 目标 |
|---|---|---|
| **物理对齐度** | 预测萌生点 vs Griffith 应力集中点距离 | < 5% patch 尺寸 |
| **物理覆盖率** | 预测轨迹落在真值 mask 内的比例 | > 95% |
| **3D 重投影误差** | UV 逆映射后 3D 坐标 vs 真值 3D 坐标 | < 5% 表面尺寸 |
| **多视图一致性** | 3 视角预测 IoU | > 0.7 |
| **位置 6D 误差** | 平移 + 旋转误差 | < 1cm + < 5° |
| **覆盖距离** | Chamfer / Hausdorff（与 v5-α 相同）| < 10 像素 |
| **关键点 MAE** | 与真值关键点平均像素误差 | < 3 像素 |
| **bbox IoU** | 与真值 bbox 交并比 | > 0.85 |
| **跨材料泛化** | train on porcelain, test on stoneware | 指标不下降 > 20% |

### 8.3 v5-β 风险

| 风险 | 说明 | 缓解 |
|---|---|---|
| 真实数据采集成本 | 1 次烧制 ~12 h × 5000 样本 = 数年 | 与陶艺作坊长期合作 |
| UV 展开失真 | 凹形状展开误差大 | 选凸为主，凹形状手工分割 |
| 标注一致性 | 多人标注 IoU 难保证 | ≥ 3 人标注，取多数一致 |
| 模型迁移 | v5-α 训练好的不能直接用 | 骨干可复用；GP/输出头重训 |
| Streamlit GUI | 部署到不同 OS | 优先 Windows + Web fallback |
