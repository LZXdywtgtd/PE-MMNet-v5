# 项目算法与训练实验设计报告

> PE-MMNet v4 多模态裂纹预测系统
> 版本：4.6.11 | 更新：2026-08-12

---

## 一、问题背景

日用陶瓷在热震过程中会产生裂纹，需要实时预测裂纹的位置、尺寸和密度。

**物理约束**：
- 裂纹密度随温度下降单调递增（格里菲斯断裂准则）
- 裂纹不可逆
- 裂纹位置与应力集中区域相关

---

## 二、算法设计

### 2.1 非对称双分支架构

```
输入
├── 1D 分支：温度时序 (B, 300)
│   └── Micro + Macro 1D-CNN + Self-Attention → 64 维
└── 2D 分支：温度场+应力场 (B, 2, H, W)
    └── 骨干网络 → 512 维特征

融合：Cross-Attention → 输出 Head
输出：检测向量 / 分割掩膜
```

### 2.2 模型变体

| 变体 | 2D 骨干 | 检测方式 | 特点 | 等级 |
|------|---------|----------|------|------|
| `resnet18` | ResNet-18 | MLP 回归 | 默认基线 | L1 |
| `swin_yolo` | Swin-Tiny | YOLO 网格回归 | 空间定位强 | L1+ |
| `vit_yolo` | ViT-Small | YOLO 网格回归 | 全局注意力 | L1 |
| `swin_yolo_patchtst` | Swin-Tiny + PatchTST | YOLO 网格回归 | 长程时序依赖 | L1+ |
| `detr` | ResNet-18 | Transformer (100 queries) | 全局感知 | L1+ |

加 5 个消融变体（`1d_only`, `2d_only`, `concat`, `add`, `cross_attn`），用于消融实验。

### 2.3 Cross-Attention 融合

双向交叉注意力实现"时域驱动力 × 空间薄弱位置"的物理耦合：

```
方向 1（图像查询温度）：Q_2d → K_1d, V_1d
方向 2（温度查询图像）：Q_1d → K_2d, V_2d
融合：concat → 输出 Head
```

### 2.4 训练/推理模式

新变体用 `self.training` 区分：

- **训练**：返回原始预测（给 loss 函数）
- **推理**：取最佳预测 → 融合 → 输出 head

## 三、损失函数设计

### 3.1 基础模型

```
L_total = λ_mse · L_mse + λ_mono · L_mono + λ_loc · L_loc + λ_conf · L_conf
```

| 损失 | 物理原理 | 默认权重 |
|------|----------|----------|
| L_mse | 密度预测误差 | 1.0 |
| L_mono | 格里菲斯断裂准则 | 0.1 |
| L_loc | DIoU 定位 | 1.0 |
| L_conf | BCE 置信度 | 1.0 |

### 3.2 单调性损失

```python
L_mono = Σ max(0, pred[i+1] - pred[i]) / (n-1)
```

仅当密度下降时计算惩罚，保证物理自洽性。

### 3.3 YOLO 损失

```
L_total = λ_box · L_box + λ_conf · L_conf + λ_mono · L_mono
```

网格分配：`YOLOTargetAssigner(grid_size=16, nearby_range=2)`。

### 3.4 DETR 损失

```
L_total = λ_bbox · L_bbox + λ_conf · L_conf + λ_mono · L_mono + 0.5 · L_supervise
```

Hungarian 匹配选最佳 query，supervise 损失是经融合层输出的额外监督。

## 四、高级优化

### 4.1 分阶段训练

先在短序列数据上预训练，再在全部数据上微调。

### 4.2 门控多模态融合

温度/应力分治策略，通过门控机制自适应选择融合权重。

```bash
python run_train.py --variant resnet18 --fusion gated
```

### 4.3 ThermalCutMix

物理安全增强：仅混合温度通道，应力通道保持不变。

```bash
python run_train.py --aug_cutmix_prob 0.3
```

### 4.4 坐标注意力

保留位置信息，所有变体均支持。

```bash
python run_train.py --variant resnet18 --use_coord_attn
```

### 4.5 三通道时序输入

```bash
python run_train.py --triple_channel
```

## 五、训练策略

### 5.1 显存自适应

`auto_select_config()`（`run_train.py:201`）：

| 空闲显存 | 图像尺寸 | 批次大小 | FP16 |
|----------|----------|----------|------|
| ≥10 GB | 512 | 16 | ✔ |
| 6-10 GB | 512 | 8 | ✔ |
| 4-6 GB | 384 | 8 | ✔ |
| <4 GB | 256 | 4 | ✗ |

> FP16 仅对 `swin_yolo` / `vit_yolo` / `detr` / `swin_yolo_patchtst` 4 个新变体默认开启。

### 5.2 早停机制

`patience = 30`：连续 30 epoch 验证损失无改善则停止（默认）。

### 5.3 续训机制

`train_model` 接收 `start_epoch` 和 `best_loss`（v4.6.10+）：

- 续训时从 `e{N+1:03d}_last.pt` 加载
- 透传 `saved_epoch` 和 `best_loss`
- 训练循环从 `start_epoch` 开始

## 七、实验设计

### 7.1 消融实验

`run_train.py` 提供 `--mode ablation` 入口：

```bash
# 列出所有消融变体并准备实验
python run_train.py --mode ablation

# 手动跑各消融变体
python run_train.py --variant 1d_only --epochs 50
python run_train.py --variant 2d_only --epochs 50
python run_train.py --variant concat --epochs 50
python run_train.py --variant add --epochs 50
python run_train.py --variant cross_attn --epochs 50
python run_train.py --variant resnet18 --epochs 50  # 对照
```

`team_train.py` 也可加载含消融任务的 JSON 配置。

### 7.2 时间偏移预测

```bash
python run_train.py --predict_offset 0  # 当前
python run_train.py --predict_offset 1  # 0.05s 后
python run_train.py --predict_offset 2  # 0.1s 后
```

### 7.3 团队协作实验

```bash
python team_train.py
# 选择任务编号即可开始训练
```

详细见 [团队协作训练指南](../collaboration/团队协作训练指南.md)。

## 八、后续优化方向

1. **损失函数**：CIoU、更复杂的单调性约束
2. **注意力机制**：更多位置感知变体
3. **数据增强**：物理约束增强（除 ThermalCutMix 外）
4. **模型压缩**：知识蒸馏、量化
5. **多任务统一**：检测+分割联合的更紧密设计
