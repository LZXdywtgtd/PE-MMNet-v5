## 三、team_train_v5.py 命令详解

### 3.1 `--list-tasks`：列出任务

```bash
$ python team_train_v5.py --list-tasks
  任务清单 (10 个):
    V5A1   | L1 | patch 仿真器升级（S1–S4 + S7） | deps=[]
    V5A2   | L1 | Spline 输出头 + GP 模块 | deps=[]
    V5A3   | L1 | 覆盖距离 loss（B 样条 + Hausdorff） | deps=[]
    V5A4   | L2 | 5 变体输出头迁移 | deps=['V5A2', 'V5A3']
    V5A5   | L2 | 变长训练循环（trainer_v5） | deps=['V5A4']
    V5A6   | L3 | 5 变体训练 + 评估（150 epoch） | deps=['V5A1', 'V5A5']
    V5B3   | L1 | 裂纹标注工具（V5B3） | deps=[]
    V5B4   | L1 | 位置图像提取（V5B4） | deps=[]
    V5B6   | L1 | npz 磁盘缓存（V5B6） | deps=[]
    V5B7   | L1 | 团队训练脚本（V5B7） | deps=[]
```

**关键行为**：
- 仅加载 `V5*` 前缀任务（v4 残留 `team_optimization.json / team_baseline.json` 自动忽略）
- 模块任务（如 V5A1）显示 `args: "--module simulator"`，运行时**直接跑对应单元测试**而非 GPU 训练

### 3.2 交互式菜单

```bash
$ python team_train_v5.py
```

进入交互式菜单，按数字键选择任务：
- `[1] ▶ [可执行] V5A1 patch 仿真器` → 按 `1` 执行
- `[a]` → 自动执行所有可执行任务
- `[i]` → 导入队友检查点
- `[q]` → 退出

状态图标：
- `✓` 已完成（`is_complete=True`）
- `▶` 待执行（依赖已满足 + 硬件足够）
- `!` 待执行（依赖已满足 + 硬件警告）
- `🔒` 等待依赖
- `⏸` 中断（有检查点但未完成）

### 3.3 `--auto`：自动执行

```bash
# 标准模式：遇硬件警告任务要求确认
python team_train_v5.py --auto

# 强制模式：跳过硬件警告
python team_train_v5.py --auto --force
```

**关键行为**：
- 拓扑排序：先执行无依赖任务（V5A1/V5A2/V5A3），再执行依赖任务（V5A4 → V5A5 → V5A6）
- 动态扫描：每次完成后重新检查依赖，新解锁的任务立即加入队列
- 中断恢复：被中断的任务（`is_complete=False` 但有检查点）优先恢复

### 3.4 `--import`：导入队友检查点

```bash
python team_train_v5.py --import
```

按提示输入队友检查点所在文件夹路径，逐文件复制到本地 `checkpoints/`：
- 已存在文件跳过
- 不存在文件复制
- 复制完成后日志记录到 `logs/team_training_v5.log`

## 四、模块任务路由（`_V5_MODULE_TEST_MAP`）

team_train_v5.py 对 `V5A*` 等无 GPU 训练任务的处理方式：

| 任务 ID | 模块 | 对应测试文件 |
|---|---|---|
| V5A1 | simulator | `tests/test_patch_simulator_v5.py` |
| V5A2 | heads | `tests/test_spline_head.py` + `tests/test_gp_module.py` |
| V5A3 | loss | `tests/test_ordered_kp_loss.py` |
| V5A4 | backbones | `tests/test_pe_tsnet_v5.py` |
| V5A5 | trainer | `tests/test_trainer_v5_smoke.py` |
| V5B3 | annotator | `tools/crack_annotator.py`（冒烟测试）|
| V5B4 | position | `data/position_extractor.py`（冒烟测试）|
| V5B6 | cache | `data/patch_dataset_v5.py`（冒烟测试）|
| V5B7 | team | （本文件自身，无需测）|

**行为**：当 `args` 含 `--module <name>` 时，team_train_v5.py 直接 `subprocess.run(["python", "<test_file>"])`，把测试结果作为任务完成度。

## 五、v5-α 单任务工作流（备选）

如果你不需要完整 team_train_v5 框架（只想跑单个任务），可直接：

### 5.1 跑单个 V5A6 任务

```bash
# 完整命令模板
python run_train_v5.py \
    --variant <5 变体之一> \
    --epochs 150 \
    --n_samples 1000 \
    --batch_size 4 \
    --lr 1e-4 \
    --log_dir logs/training_history/<run_name>
```

### 5.2 跑 V5A6（5 变体评估）

```bash
mkdir -p logs/training_history

for v in resnet18 swin_yolo vit_yolo detr swin_yolo_patchtst; do
    python run_train_v5.py \
        --variant $v \
        --epochs 150 \
        --n_samples 1000 \
        --batch_size 4 \
        --lr 1e-4 \
        --log_dir logs/training_history/v5a6_$v
done
```

### 5.3 断点续训

```bash
python run_train_v5.py \
    --variant resnet18 \
    --epochs 200 \
    --resume logs/training_history/v5a6_resnet18/checkpoints/latest.pt
```

### 5.4 监控进度

```bash
# 实时看 CSV 末尾
tail -f logs/training_history/v5a6_resnet18/training_history.csv
```

```python
# 画 loss 曲线
import pandas as pd
df = pd.read_csv("logs/training_history/v5a6_resnet18/training_history.csv")
df.plot(x="epoch", y=["train_loss", "val_loss"])
```
