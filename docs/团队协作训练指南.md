| 复杂度来源 | v5-α 是否需要 |
|---|---|
| 任务 ID 冲突解决 | 单人无需 |

**v5-β 启动条件**：v5A6 评估报告显示 5 变体均跑通，且与 v4 baseline 对比有提升。

## 三、v5-α 单任务工作流（当前）

### 3.1 跑单个任务

```bash
# 完整命令模板
python run_train_v5.py \
    --variant <5 变体之一> \
    --epochs 150 \
    --n_samples 1000 \
    --batch_size 4 \
    --lr 1e-4 \
    --log_dir logs/training_history/<run_name>
```

### 3.2 跑 V5A6（5 变体评估）

按 `tasks/team_v5_alpha.json` 中 V5A6 的定义：

```bash
mkdir -p logs/training_history

for v in resnet18 swin_yolo vit_yolo detr swin_yolo_patchtst; do
    python run_train_v5.py \
        --variant $v \
        --epochs 150 \
        --n_samples 1000 \
        --batch_size 4 \
        --lr 1e-4 \
        --log_dir logs/training_history/v5a6_$v
done
```

### 3.3 断点续训

```bash
# 续训到 200 epoch
python run_train_v5.py \
    --variant resnet18 \
    --epochs 200 \
    --resume logs/training_history/v5a6_resnet18/checkpoints/latest.pt
```

### 3.4 监控进度

```bash
# 实时看 CSV 末尾
tail -f logs/training_history/v5a6_resnet18/training_history.csv
```

```python
# 画 loss 曲线
import pandas as pd
df = pd.read_csv("logs/training_history/v5a6_resnet18/training_history.csv")
df.plot(x="epoch", y=["train_loss", "val_loss"])
```

## 四、v5-β 启动后如何实现团队协作？

> **仅为占位说明**，v5-α 阶段不需要。

### 4.1 v4 → v5-α 适配清单

| v4 概念 | v5-α 对应 | 适配方式 |
|---|---|---|
| `team_train.py` | `run_train_v5.py` | 直接复制 `team_train.py`，把 `subprocess.run(["python", "run_train.py", ...])` 改为 `["python", "run_train_v5.py", ...]` |
| `tasks/team_baseline.json` | `tasks/team_v5_alpha.json` | 改 CLI 参数为 v5-α 的（`--variant` / `--epochs` / `--n_samples`） |
| 检查点路径 `checkpoints/{variant}/{subdir}/{task}_off{N}_e{NNN}_{best|last}.pt` | `logs/training_history/<run>/checkpoints/{best\|latest}.pt` | 重写 `_resolve_task_id` 与 `get_completed_tasks` |
| `is_complete` 字段 | 无 | 续写：v5-α `best.pt` 写盘即代表完成 |
| `team_training.log` | `CSVHistory` | 改写日志解析 |

### 4.2 v5-β 新增功能（暂未实现）

- 检查点共享（`import_checkpoint`）
- 自动等级检测（L1-L4，按显存分配任务）
- 任务进度可视化（Streamlit GUI）
- 失败重试 + 指数退避

### 4.3 已知 v4 团队协作 bug（v5-α 暂不触发）

详见 [v5_已知问题.md](v5_已知问题.md) "继承自 v4 的已知 Bug"：
- B004: `tasks/*.json` 顶层 dict 形式静默丢弃

- B006: `DEFAULT_TRAIN_TASKS` 内置任务缺 `subdir`

- B008: `get_completed_tasks` 只扫 `*_best.pt`
- B009: `import_checkpoint` 复制到 `checkpoints/` 根目录
