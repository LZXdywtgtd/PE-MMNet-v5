> PE-MMNet v5-α 损失函数配置与调参指南
> 版本：5.0.5-alpha | 更新：2026-08-24
>
> **继承说明**：本文件由 v4.6.11 同名文档**完全重写**。v5-α 抛弃了 v4 的 6 维向量损失 / 单调性损失 / `--lambda_mono` 硬编码等机制，采用全新的 4 项加权损失体系。

## §0. v5-α 损失体系（30 秒）

```python
total = λ_cov * coverage_loss         # 主损失（Catmull-Rom 样条 + Hausdorff/Chamfer）
      + λ_bbox * bbox_loss            # Smooth L1 on bbox
      + λ_gp * gp_log_marginal_likelihood   # GP 嵌入模块正则
      + λ_poisson * poisson_prior     # 泊松过程先验（稀疏性约束）
```

**默认权重**（V5A5 trainer 默认）：

| 权重 | 默认值 | 调参范围 |
|------|--------|----------|
| `lambda_coverage` | 1.0 | 0.5 - 2.0 |
| `lambda_bbox` | 1.0 | 0.5 - 2.0 |
| `lambda_gp` | 0.1 | 0 - 0.5 |
| `lambda_poisson` | 0.05 | 0 - 0.2 |

## §1. 损失分量详解

### 1.1 coverage_loss（主损失）

**位置**：`training/ordered_kp_loss.py` `OrderedKeypointLoss._coverage_loss`

**算法**：

1. 预测关键点（K 个有序点）→ Catmull-Rom 样条拟合
2. 在曲线上等弧长采样 M=200 个点（默认）
3. 真值裂纹像素 → 找每个像素到曲线的最小距离
4. **Chamfer** 模式：双向平均（curve→pixel + pixel→curve）
5. **Hausdorff** 模式：取最大最小距离（对离群点敏感）

**CLI 参数**：

```bash
--coverage_mode {chamfer|hausdorff}    # 默认 chamfer
--M 200                                # 样条采样点数
```

**调参建议**：

| 现象 | 调整 |
|------|------|
| 预测轨迹平滑但偏离 mask | `--coverage_mode hausdorff` |
| 训练震荡 | `--M 300`（采样更密） |
| 想强调边缘细节 | `--coverage_mode hausdorff --M 100` |

### 1.2 bbox_loss

**位置**：`training/ordered_kp_loss.py` `OrderedKeypointLoss._bbox_loss`

**算法**：Smooth L1（Huber）on bbox (x1, y1, x2, y2)。SplineHead 输出已保证 x1≤x2, y1≤y2。

**调参建议**：

| 现象 | 调整 |
|------|------|
| bbox 偏移但关键点贴合 | `--lambda_bbox 2.0` |
| bbox 噪声大 | `--lambda_bbox 0.5` |

### 1.3 gp_log_marginal_likelihood

**位置**：`models/gp_module.py` `GPModule.log_marginal_likelihood`

**算法**：GP 在 batch 内的 log marginal likelihood（含 ℓ + σ² 惩罚 + 数据拟合项）。

**调参建议**：

| 现象 | 调整 |
|------|------|
| 物理约束过强、loss 难收敛 | `--lambda_gp 0`（关闭 GP）|
| 想强调物理一致性 | `--lambda_gp 0.3` |
| GP 模块过拟合 | `--lambda_gp 0.05` |

**已知问题（V5-014/015）**：GP 依赖 batch 内 L2 归一化，训练/推理 batch stats 不一致 → 平滑强度有微小差异。v5-α MVP 接受；v5-β 改为 running stats。

### 1.4 poisson_prior

**位置**：`training/ordered_kp_loss.py` `OrderedKeypointLoss._poisson_prior`

**算法**：泊松过程先验，鼓励关键点稀疏分布。

**调参建议**：

| 现象 | 调整 |
|------|------|
| 关键点扎堆 | `--lambda_poisson 0.2` |
| 关键点过于稀疏 | `--lambda_poisson 0` |

## §2. CLI 参数全表

### 2.1 训练参数

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `--variant` | resnet18 | 5 变体之一 |
| `--epochs` | 10 | 总 epoch 数 |
| `--lr` | 1e-4 | 学习率 |
| `--batch_size` | 4 | 批大小 |
| `--seed` | 42 | 随机种子（影响 RNG + 数据生成）|

### 2.2 数据参数

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `--n_samples` | 100 | 仿真样本数 |
| `--patch_size` | 256 | patch 像素尺寸 |
| `--min_kpts` | 8 | 关键点下界 |
| `--max_kpts` | 16 | 关键点上界 |
| `--seq_len` | 300 | 1D 时序长度（v4 沿用） |
| `--crack_stress_threshold_MPa` | 50.0 | 裂纹萌生应力阈值 |
| `--no_aug` | False | 禁用数据增强 |
| `--fast_thermal` | False | 用 1 min 短周期（仅测试）|

### 2.3 损失权重

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `--lambda_coverage` | 1.0 | 主损失权重 |
| `--lambda_bbox` | 1.0 | bbox Smooth L1 |
| `--lambda_gp` | 0.1 | GP LML |
| `--lambda_poisson` | 0.05 | 泊松先验 |
| `--coverage_mode` | chamfer | 覆盖距离模式 |
| `--M` | 200 | 样条采样点数 |

### 2.4 模型参数

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `--pretrained_2d` | False | ImageNet 预训练 |
| `--no_gp` | False | 禁用 GP 模块 |

### 2.5 设备 / 路径

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `--device` | None | cuda / cpu（None = 自动）|
| `--log_dir` | logs/training_history/run_train_v5 | 输出目录 |
| `--resume` | None | 续训 checkpoint 路径 |
| `--save_every` | 1 | 每 N epoch 保存 latest |

## §3. 调参场景

### 3.1 训练初期震荡

```bash
--lr 5e-5 --lambda_coverage 0.5 --lambda_gp 0.05
```

### 3.2 训练后期想强调细节

```bash
--coverage_mode hausdorff --lambda_coverage 2.0 --lambda_poisson 0.1
```

### 3.3 GP 消融实验

```bash
# 关 GP
--no_gp --lambda_gp 0
```

### 3.4 增大关键点范围（更密集轨迹）

```bash
--min_kpts 12 --max_kpts 24
```

### 3.5 内存紧张

```bash
--batch_size 2 --patch_size 128 --n_samples 50
```

```
epoch, train_loss, val_loss, best_val_loss, lr,

```

### 4.2 V5A6 评估指标（待定）

候选指标（与导师讨论后确定）：

| 指标 | 说明 | 优先级 |
|------|------|--------|
| **物理对齐度** | 裂纹萌生点 vs Griffith 应力集中点 | 高（导师问"能推得出来"）|
| **物理覆盖率** | 预测轨迹落在 crack_mask 95% 内 | 高 |
| **覆盖距离 ↓** | Chamfer/Hausdorff 距离 | 中 |
| **关键点 MAE ↓** | 关键点位置误差 | 中 |
| **bbox IoU ↑** | bbox 交并比 | 中 |

> ⚠️ v5-α 与 v4 输出格式不同，**R²/RMSE/违反率** 这些 v4 指标**不适用**。
> 比较 v4 与 v5 需在统一指标下重写（V5A6 启动前确定）。

## §6. 常见问题

| 问题 | 解决方案 |
|------|----------|
| Loss = NaN | `--lr 1e-4`（默认）；空真值像素已 surrogate 处理（V5-018）|
| 训练震荡 | `--lr 5e-5` + `--lambda_coverage 0.5` |
| GP 难收敛 | `--no_gp --lambda_gp 0`（消融实验）|
| 关键点扎堆 | `--lambda_poisson 0.2` |
| 关键点偏离 mask | `--coverage_mode hausdorff --lambda_coverage 2.0` |
| 续训 epoch 接不上 | 检查 `load_checkpoint` 是否传入正确路径 |

## §8. v5-β 调参规划（待启动）

> **触发条件**：V5A6 评估通过 → 启动 V5B1-V5B8

### 8.1 v5-β 新增损失分量

| 损失 | λ 默认值 | 调参范围 | 说明 |
|------|----------|----------|------|
| `uv_projection_loss` | 1.0 | 0.5-2.0 | UV 逆映射回 3D 坐标与真值误差 |

### 8.2 v5-β 调参场景

| 现象 | 调整 |
|------|------|
| UV 逆映射误差大 | `--lambda_uv_projection 2.0` |
| 位置预测偏差大 | `--lambda_position_6d 1.0` |
| 多视角预测不一致 | `--lambda_multi_view 0.5` |
| 真实数据过拟合 | `--use_strong_aug` + `--dropout 0.3` |

### 8.3 v5-β GP 模块改进（修复 V5-014/015）

```python
# v5-α：batch 内 L2 归一化
GPModule._normalize_for_kernel(x)  # 按 batch 内 L2 范数

# v5-β：running stats
GPModule.forward(x, running_mean, running_std)  # 用训练集统计量
```
