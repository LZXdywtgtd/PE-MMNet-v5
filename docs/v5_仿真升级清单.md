# v5 仿真升级清单

> v5-α 的 patch 仿真器相对 v4 的边界条件升级清单。
>
> v4 仿真 = 1cm × 1cm 平面 + 单向热传导；v5-α = 256×256 patch + 多物理场。

---

## S1. 多方向热交换

### 现状（v4）

```python
# v4 单向热传导（仅上方冷风，其他方向热绝缘）
∂T/∂t = α ∂²T/∂z²  # 仅 z 方向
boundary: top=convection, others=insulated
```

### v5-α 升级

```python
# v5-α 全方向热传导 + 多边界条件
∂T/∂t = α ∇²T  # x, y 方向都计算

boundary:
  top:    convection + radiation          # S2 配合
  side:   convection + radiation
  bottom: convection + radiation
  interior: 热源/吸热（按 patch 物理属性）
```

### 实现要点

1. 偏微分方程离散化：用有限差分（FDM）替换 v4 的简化积分
2. 时间步进：自适应步长（基于CFL 条件）
3. 各方向热交换系数：从窑体尺寸先验推算（见 `config.json: kiln_dims_cm`）

### 验证指标

- 与解析解（单方向稳态）的对比误差 < 5%
- 收敛稳定性：1000 步无发散

## S2. 表面辐射（Stefan-Boltzmann）

### 物理方程

```python
q_rad = ε σ (T_surface⁴ - T_env⁴)
```

参数：
- ε：发射率（陶瓷表面典型 0.85–0.95）
- σ：Stefan-Boltzmann 常数 = 5.67 × 10⁻⁸ W/(m²·K⁴)
- T_surface：表面温度
- T_env：环境温度

### 实现位置

`data/patch_simulator_v5.py: SurfaceRadiation` 类

### 验证指标

- 表面热损失占总热损失的 20–40%（典型值）
- 与文献实验数据对比（陶瓷烧制场景）

## S3. 内部应力松弛（粘弹性）

### 物理模型

采用 Maxwell 粘弹性模型（最简）：

```python
σ(t) + τ σ̇(t) = E ε(t)
```

- σ：应力
- ε：应变
- E：弹性模量
- τ：松弛时间常数

### v4 现状

无应力松弛假设 → 应力瞬间达到稳态（不符合陶瓷材料实际）

### v5-α 升级

```python
class ViscoelasticStress:
    def __init__(self, E, tau):
        self.E = E       # 弹性模量，陶瓷典型 70–300 GPa
        self.tau = tau   # 松弛时间常数，典型 10–100 s
    
    def update(self, strain_rate, dt):
        # 离散化 Maxwell 模型
        ...
```

### 验证指标

- 应力松弛曲线与解析解的拟合度 > 95%
- 物理一致性：保温阶段应力下降幅度合理

## S4. 分时段升降温曲线

### 三段式（会议5 决策）

| 时段 | 温度 | 时间 | 速率 |
|---|---|---|---|
| **升温** | 室温 → 1280 °C | 240 min | 5 °C/min |
| **保温** | 1280 °C 维持 | 30 min | 0 °C/min |
| **降温** | 1280 °C → 室温 | 400 min | 3 °C/min |

总时长 ≈ 11 小时（典型烧制周期）

### 配置位置

`config.json: thermal_profile`

```json
{
  "thermal_profile": {
    "ramp_up_c_per_min": 5.0,
    "soak_temp_c": 1280.0,
    "soak_duration_min": 30,
    "cool_down_c_per_min": 3.0
  }
}
```

### 仿真输出

仿真器在每个时间步输出：
- 当前温度场 T(x, y, t)
- 当前应力场 σ(x, y, t)

裂纹萌生/扩展判据在 S5–S6 中定义（可选）。

## S5. 裂纹萌生判据（Griffith）

### 物理判据

```python
σ ≥ σ_c = √(2 E γ_s / (π a))
```

- σ_c：临界应力
- E：弹性模量
- γ_s：表面能（陶瓷典型 1–10 J/m²）
- a：缺陷尺寸

### 实现方式

- 扫描整个 patch，对每个像素判断是否达到 Griffith 判据
- 萌生点集：所有满足 σ ≥ σ_c 的像素

### v5-α 状态

**可选**。v5-α 可用简化判据（基于热应力阈值），S5 完整实现留待 v5-α 后期或 v5-β。

## S6. 裂纹扩展轨迹生成（LEFM）

### 物理模型

线弹性断裂力学（Linear Elastic Fracture Mechanics）：

```python
K_I = σ √(π a)   # I 型应力强度因子
K_IC = √(2 E γ_s)  # 断裂韧性

# 判据：K_I ≥ K_IC 时裂纹扩展
```

### 扩展方向

按最大周向应力理论（Maximum Tangential Stress）：

```python
θ_0 = arccos(3 σ_22 / (σ_11 + σ_22 + 2 √(σ_11² + σ_22²)))
```

### v5-α 状态

**可选**。实现复杂，需要网格化应力场。

## S7. 像素级裂纹 mask 输出（必做）

### 输出格式

```python
crack_mask: np.ndarray  # (256, 256), dtype=uint8
  # 0 = 非裂纹
  # 255 = 裂纹像素
```

### 生成方式

1. **仿真路线**（S5–S6 启用时）：从萌生点出发，按 LEFM 方向扩展，渲染为 mask
2. **简化路线**（v5-α 早期）：基于应力场的阈值 + 后处理生成

### 后处理

- 连通域分析：保留最长的连通裂纹
- 形态学闭运算：连接断裂处
- 骨架化：用于提取关键点 GT

### 配套：关键点 GT 生成

```python
# 从 crack_mask 提取关键点 GT
def extract_keypoints_gt(crack_mask, min_kpts=8, max_kpts=16):
    # 1. 骨架化
    skeleton = morphology.skeletonize(crack_mask > 0)
    
    # 2. 最长路径搜索
    longest_path = find_longest_path(skeleton)  # N 个骨架点
    
    # 3. 等弧长采样 K 个点（K ∈ [min_kpts, max_kpts]）
    K = random.randint(min_kpts, max_kpts)
    keypoints = resample_by_arclength(longest_path, K)
    
    # 4. bbox = 骨架点 + 像素级的包络矩形
    bbox = compute_bbox(skeleton)
    
    return keypoints, bbox
```

```
S7 (像素级 mask 输出)
  ↑
```
