## §一. v5-α 概览（**当前 MVP**）

**目标**：在虚拟仿真数据上验证算法骨架（patch 仿真 + SplineHead + GP + 覆盖距离 loss）。

**完成度**：V5A1-V5A5 已完成 ✅，V5A6 待启动。

**接口**：`run_train_v5.py`，5 变体，仿真自包含数据。

---

## §二. v5-β 概览（**详细规划**）

**目标**：把 v5-α 验证过的算法骨架**接入真实 3D 烧制数据**，完成数据闭环。

**状态**：待 v5-α V5A6 评估通过后启动。预估 V5B1-V5B8 共 8 个任务，~3-4 月工作量。

**核心升级**：

| 维度 | v5-α | v5-β |
|---|---|---|
| **数据** | 256×256 仿真 patch | 真实 3D 陶瓷烧后图（cup/bowl/plate）|
| **输入** | 温度场 + 应力场 + 热力图（3 通道 2D）| 真实烧后 RGB 图 + 3D 形状先验 + 位置图像 |
| **形状** | 形状无关 | UV 展开（3D mesh → 2D patch + 逆映射）|
| **多角度** | 无 | 多机位窑内采图（≥ 2 个角度）|
| **位置感知** | L3 默认关闭 | L0-L4 完整管线 |
| **GT 标注** | 仿真器生成 | crack_annotator 工具（人工标注）|
| **数据缓存** | 内存（2GB/千样本）| 磁盘 hdf5/npz（V5-B016）|
| **团队协作** | 单任务 | team_train_v5.py + Streamlit GUI |
| **模型架构** | 5 变体（骨干不变）| 同 5 变体 + UV 映射模块 |

## §三. v5-α 详细范围

### §3.1 v5-α **实现**的内容

| 项 | 说明 |
|---|---|
| **表示** | 256×256 像素的"虚拟陶瓷表面 patch"（形状无关）|
| **模态** | 3 路：温度场 + 应力场 + 热力图（均为 256×256）|
| **位置图像** | L3_disabled（默认关闭）|
| **bbox** | 4 维（x1, y1, x2, y2）归一化角点 |
| **关键点** | 8–16 动态有序点，浮点 (x, y) 坐标 |
| **总输出维度** | 4 + 16（bbox + max 关键点）|
| **主损失** | Catmull-Rom 样条 + Hausdorff/Chamfer 覆盖距离（λ=1.0）|
| **bbox 损失** | Smooth L1（λ=1.0）|
| **GP 模块** | RBF 核 + ℓ/σ² 可学习（λ=0.1，默认启用）|
| **泊松先验** | 关键点稀疏约束（λ=0.05）|
| **5 变体** | resnet18 / swin_yolo / vit_yolo / detr / swin_yolo_patchtst |
| **骨干网络** | v4 沿用，**输出头**替换为 SplineHead |
| **跨模态融合** | v4 Cross-Attention / Gated Fusion 沿用 |
| **patch 仿真器** | S1-S4 + S7（多方向热交换 + 辐射 + 应力松弛 + 三段曲线 + 像素级 mask）|
| **数据生成** | 仿真自包含（无需真实数据）|
| **训练** | TrainerV5 + 变长 batch + 断点续训 + CSV 历史 |
| **验证** | 仿真数据 train/val split 即可完成 |

### §3.2 v5-α **不实现**的内容（明确排除）

| 不实现项 | 原因 |
|---|---|
| **真实 3D 物体**（杯/碗/盘等任意形状）| v5-α 在虚拟 patch 上验证形状无关性 |
| **UV 展开** | 依赖 3D 物体几何信息 |
| **多角度拍摄管线** | 依赖真实 3D 物体 |
| **真实烧制数据采集流程** | 依赖陶艺作坊合作落地（待 v5-β 启动）|
| **位置图像 L0/L1**（完整角点检测 + 单应性）| 依赖多角度拍摄与标定物 |
| **crack_annotator 标注工具** | 依赖真实烧后图采集 |
| **3D FEM 仿真** | 工作量大，且非 v5-α MVP 必需 |
| **Griffith 裂纹萌生判据**（S5 完整版）| v5-α MVP 用应力阈值简化 |
| **LEFM 裂纹扩展**（S6 完整版）| v5-α MVP 用最长连通域简化 |
| **team_train.py 协作框架** | v5-α 单任务单人足够 |
| **Streamlit GUI** | v5-α MVP 只需 CLI |

## §四. v5-α vs v4 关键差异

| 维度 | v4.6.11 | v5-α |
|---|---|---|
| **空间维度** | 1cm × 1cm 平面 | 256×256 patch（任意尺度）|
| **热传导** | 单向（上→下）| **多方向**（S1）|
| **辐射** | 无 | **Stefan-Boltzmann**（S2）|
| **应力松弛** | 无 | **粘弹性模型**（S3）|
| **温度曲线** | 简单升温 | **三段：升温 / 保温 / 降温**（S4）|
| **裂纹物理** | 启发式 | **Griffith + LEFM**（S5-S6，可选）|
| **输出格式** | 6 维向量 / 二值掩膜 | **bbox + 8–16 动态关键点** |
| **物理约束** | 单调性损失 | **GP 嵌入模块 + 泊松先验** |
| **数据** | 真实烧制实验 | **仿真自包含** |

## §五. 位置图像 5 级降级（v5-α 用 L3 默认）

| 级别 | 数据可得性 | 处理方式 | 模型行为 |
|---|---|---|---|
| **L0 完整** | 多角度 + 标定物 + 烧后图 | 角点 + 单应性 + bbox → 6D | 完整 4 模态融合 |
| **L1 单目有窑** | 烧前单张 + 窑体可见 | 角点检测 → 窑体框 → 6D | 完整 4 模态融合 |
| **L2 仅陶瓷** | 烧前单张 + 看不到窑体 | 仅记陶瓷数量 / 方位 | 退化为陶瓷计数 1D |
| **L3 元数据** | 无照片 + 人工记录 | `cart_id + layer_idx` → 6D 默认值 | 位置模态用默认值 |
| **L4 无** | 全部缺失 | 6D = 0 + mask | 位置分支屏蔽，模型退化为 3 模态版 |

**v5-α 默认 = L3_disabled**：位置图像分支存在但默认关闭，避免对 3D 落地有依赖。

## §六. v5-β 详细范围（**正式规划**）

### §6.1 v5-β **实现**的内容

#### A. 数据层

| 模块 | 内容 | 说明 |
|---|---|---|
| **真实 3D 物体库** | cup / bowl / plate / vase 共 4 类 | 用 Blender 建模；OBJ/PLY 格式 |
| **UV 展开管线** | 3D mesh → 2D UV patch + 逆映射（patch → 3D）| `tools/uv_unwrap.py` + `data/uv_mapper.py` |
| **多角度拍摄** | 窑内 2 机位 + 窑外 1 机位 | 标定后用 OpenCV 多视图几何 |
| **crack_annotator** | 交互式标注工具（Streamlit + OpenCV）| 输出 JSON（关键点 + bbox + mask）|
| **数据闭环** | 烧前图 → 烧后图 → 标注 → 训练 | 端到端 |
| **磁盘缓存** | hdf5 / npz（替代内存 cache）| 适配 10000+ 样本 |

#### B. 模型层

| 模块 | 内容 | 说明 |
|---|---|---|
| **UV 映射模块** | SplineHead 输出 + UV 逆映射 → 3D 空间 | 在 v5-α SplineHead 基础上加 `UVInverseHead` |
| **位置图像 L0/L1** | 角点检测 + 单应性 + 6D pose | `data/position_extractor.py`（v5-α 占位 → v5-β 实现）|
| **3D FEM 仿真**（高成本，可选）| 替代 2D patch 仿真器 | v5-α 算法骨架不变，换数据源 |
| **改进 GP** | running stats 归一化（V5-014/015 修复）| 替换 batch 内 L2 归一化 |
| **改进仿真判据** | Griffith S5 + LEFM S6 完整版 | 物理精度提升 |

#### C. 训练 / 部署层

| 模块 | 内容 | 说明 |
|---|---|---|
| **team_train_v5** | 团队协作训练 | 移植 v4 `team_train.py` + 适配 v5-α 任务格式 |
| **Streamlit v5 推理 GUI** | 上传烧后图 → 3D 标注 | `tools/streamlit_app_v5.py`（v5-α 占位 → v5-β 实现）|
| **model_v5 仓库** | HuggingFace 5 变体发布 | 训练完成自动上传 |
| **benchmark v5** | `benchmark_results/v5_b_comparison.md` | 与 v4 + v5-α 三方对比 |

### §6.2 v5-β **不实现**的内容（明确排除）

| 不实现项 | 原因 |
|---|---|
| **流体力学仿真**（会议 K9）| 物理建模依赖 CFD，工作量极大；v5-β 仅做固体热-力耦合 |
| **陶艺作坊实地集成**（会议 K8）| 需要长期合作，超出 v5-β 时间窗口 |
| **新陶瓷材料**（金属陶瓷、3D 打印陶瓷）| 数据稀缺；v5-β 限定 4 类传统陶瓷 |
| **生产级部署**（Docker / K8s / CI/CD）| v5.1.0 之后的事 |
| **Web API 服务**（FastAPI + gRPC）| v5.1.0 之后的事 |

### §6.3 v5-β 与 v5-α 的接口差异

```python
# v5-α 接口
from data.patch_dataset_v5 import PatchDatasetV5
ds = PatchDatasetV5(patch_size=256, n_samples=100, ...)
for batch in ds:
    x_2d = batch["x_2d"]  # (B, 3, 256, 256) 仿真

# v5-β 接口（保持兼容 + 新增）
from data.patch_dataset_v5 import PatchDatasetV5
ds = PatchDatasetV5(
    patch_size=256,
    n_samples=100,
    data_source="real_3d",          # 新增：vs 仿真 "simulation"
    uv_map_path="data/uv_maps/...",  # 新增：UV 映射
    position_image_mode="L0_full",  # 新增：L0/L1 默认开启
)
for batch in ds:
    x_2d = batch["x_2d"]        # (B, 3, 256, 256) 真实
    position_6d = batch["position_6d"]  # 新增：(B, 6)
```

**关键约束**：v5-α 训练好的 5 变体**不能直接用于 v5-β**（数据格式不同：3 通道仿真 → 3 通道真实 RGB）。需重新训练，但**骨干 + SplineHead + GP 模块架构可直接复用**。

## §九. 风险与限制

### §9.1 v5-α 风险

| 风险 | 说明 |
|---|---|
| 形状无关性能否真正泛化 | v5-α 验证：在多种 patch 形状（如模拟杯/碗的曲面展开）上测 |
| 8–16 动态点的覆盖距离 loss 是否稳定 | v5-α 验证：与固定 12 点对比 |
| GP 嵌入模块是否过重 | v5-α 验证：消融实验（关 GP vs 开 GP）|

### §9.2 v5-β 风险

| 风险 | 说明 | 缓解 |
|---|---|---|
| 真实数据采集成本 | 1 次烧制 ~12 h + ~10 个样本 | 与陶艺作坊长期合作；优先复用已有数据 |
| UV 展开误差 | 3D mesh 不规则，展开有失真 | 选简单形状（杯/碗/盘），单连通 patch |
| 多机位标定 | 窑内标定物难部署 | 先用窑外相机，简化 L1 模式 |
| 标注一致性 | 人工标注有主观性 | 多人标注 + IoU 一致性检查 |
| 模型迁移 | v5-α 训练好的不能直接用 | 重新训练，但架构复用 |
