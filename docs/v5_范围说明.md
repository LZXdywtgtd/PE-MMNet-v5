# v5 范围说明

> 本文件明确划定 v5-α 的实施边界，避免范围蔓延。

---

## v5-α（当前 MVP 实施范围）

### 模型输入

| 项 | 说明 |
|---|---|
| **表示** | 256×256 像素的"虚拟陶瓷表面 patch"（形状无关） |
| **模态** | 3 路：温度场 + 应力场 + 热力图（均为 256×256） |
| **位置图像** | 可选，默认 L3 模式关闭（详见 [位置图像5级降级](#位置图像5级降级)） |

### 模型输出

| 项 | 说明 |
|---|---|
| **bbox** | 4 维（x1, y1, x2, y2）归一化角点 |
| **关键点** | 8–16 动态有序点，浮点 (x, y) 坐标 |
| **总维度** | 28 + 动态（4 bbox + 16–32 关键点） |

### 损失函数

| 损失 | 权重 | 说明 |
|---|---|---|
| **B 样条 + Hausdorff 覆盖距离**（主） | 1.0 | 见 [ordered_kp_loss.py](../training/ordered_kp_loss.py) |
| **高斯过程嵌入模块** | 0.1–0.3 | 显性物理约束，影响数据流 |
| **泊松过程先验** | 0.05–0.1 | 稀疏性约束 |

### 模型架构

- 5 个变体全部保留（resnet18 / swin_yolo / vit_yolo / detr / swin_yolo_patchtst）
- 骨干网络不变，**输出头替换**为 Spline 输出头（详见 [spline_head.py](../models/spline_head.py)）
- 跨模态融合沿用 v4 Cross-Attention / Gated Fusion

### 仿真

- patch 仿真器，边界条件升级（详见 [v5_仿真升级清单.md](v5_仿真升级清单.md)）
- S1–S4 必做（多方向热交换 + 辐射 + 应力松弛 + 三段曲线）
- S5–S7 选做（Griffith 判据 + LEFM + 像素级 GT）
- 数据生成 = 仿真自包含，无需真实烧制

### 训练与验证

- 仿真数据 train/val split 即可完成 v5-α 验证
- 真实数据验证延后到 v5-β
- 训练循环实现：`training/trainer_v5.py` + `data/patch_dataset_v5.py` + `training/data_aug_v5.py`
- 详见 [v5_架构设计.md §5](v5_架构设计.md#5-训练接口v5a5-已实现)

## v5-β（**未实现**，文档占位）

### ⚠️ v5-α 严格不实现以下内容

| 不实现项 | 原因 |
|---|---|
| **真实 3D 物体**（杯/碗/盘等任意形状） | v5-α 在虚拟 patch 上验证形状无关性，避免被3D 复杂度拖累 |
| **UV 展开**（3D → 2D 映射） | 依赖3D 物体几何信息 |
| **多角度拍摄管线** | 依赖真实3D 物体 |
| **真实烧制数据采集流程** | 依赖陶艺作坊合作落地（待 v5-β 启动） |
| **位置图像 L0/L1**（完整角点检测 + 单应性） | 依赖多角度拍摄与标定物 |
| **crack_annotator 标注工具** | 依赖真实烧后图采集 |
| **3D FEM 仿真** | 工作量大，且非 v5-α 必需 |

### 升级路径

```
v5-α (虚拟 patch)
   ↓ 算法验证成功
v5-β 启动：UV 展开 + 真实3D 物体接入
   ↓ 数据闭环
v5.1.0：真实烧制数据 + crack_annotator GT
```

## 位置图像5级降级

| 级别 | 数据可得性 | 处理方式 | 模型行为 |
|---|---|---|---|
| **L0 完整** | 多角度 + 标定物 + 烧后照片 | 角点 + 单应性 + bbox → 6D | 完整4 模态融合 |
| **L1 单目有窑** | 烧前单张 + 窑体可见 | 角点检测 → 窑体框 → 6D | 完整 4 模态融合 |
| **L2 仅陶瓷** | 烧前单张 + 看不到窑体 | 仅记陶瓷数量 / 方位 | 退化为陶瓷计数1D |
| **L3 元数据** | 无照片 + 人工记录 | `cart_id + layer_idx` → 6D 默认值 | 位置模态用默认值 |
| **L4 无** | 全部缺失 | 6D = 0 + mask | 位置分支屏蔽，模型退化为3 模态版 |

**v5-α 默认 = L3_disabled**：位置图像分支存在但默认关闭，避免对3D 落地有依赖。

## 仿真升级 vs v4

| 维度 | v4 | v5-α |
|---|---|---|
| **空间维度** | 1cm × 1cm 平面 | 256×256 patch（任意尺度） |
| **热传导** | 单向（上→下） | **多方向**（S1） |
| **辐射** | 无 | **Stefan-Boltzmann**（S2） |
| **应力松弛** | 无 | **粘弹性模型**（S3） |
| **温度曲线** | 简单升温 | **三段：升温 / 保温 / 降温**（S4） |
| **裂纹物理** | 启发式 | **Griffith + LEFM**（S5–S6，可选） |

## 与会议5 关键决策的对应

| 会议决策 | v5-α 实现 |
|---|---|
| K6（热场→应力→裂纹 逐层） | 通过 patch 仿真数据隐式实现 |
| K7（输出多输出：位置+形状+轨迹） | 8–16 动态关键点 + bbox |
| K10（多模态引入位置图像） | 位置图像分支存在，**默认关闭** |
| K11（12 关键点 + bbox，不预测宽度） | 8–16 动态（会议说"如12 个"，留出弹性）+ bbox，**无宽度** |
| K12（AI 图占位 → 真实数据替换） | v5-α 用仿真数据，v5-β 再用真实数据 |

K8（陶艺作坊合作）、K9（流体力学）→ **v5-β**。

## 风险与限制

| 风险 | 说明 |
|---|---|
| 形状无关性能否真正泛化 | v5-α 验证：在多种 patch 形状（如模拟杯/碗的曲面展开）上测 |
| 8–16 动态点的覆盖距离 loss 是否稳定 | v5-α 验证：与固定12 点对比 |
| GP 嵌入模块是否过重 | v5-α 验证：消融实验（关GP vs 开GP） |
