## 1. 结论强度分级

### 1.1 AB/AC"同盆地"（Garipov 复现）——证据强度：高

| 配对 | 直线 max | 曲线 max | 改善倍数 | 判据 |
|---|---|---|---|---|
| A↔B (s424243↔dp) | 1.0968 | 0.0560 / 0.0660 / 0.0730（三次运行） | 16~20 倍 | PASS |
| A↔C (s424243↔s424245) | 1.0884 | 0.0533 / 0.0576 | 19~20 倍 | PASS |

- 主判据（<0.1）与辅判据（≥5 倍）双过，且跨多次运行稳定
- 直线基线 max≈1.09 与工作项 2 landscape 扫描的平台值一致（口径交叉验证）
- **实验 1 补强**：z 投影消融证明低 loss 通道真实存在——中间点投回
  landscape 正则平面（z 清零）后 loss 从 ~0.015 回弹至 0.31~1.09
  （barrier 量级）。优化器确实找到了平面外的低能量绕行通道
- **5-seed z 消融补强（AB/AC 各 5 opt_seed）**：10/10 run 判据
  100% 命中——回弹 AB 0.312~1.089 / AC 0.414~1.086（判据带
  0.3~1.1），z 位移 0.57~0.79%（判据带 0.5~1.0%）；跨 opt_seed
  数字差异 <0.002pp（5 条曲线在图上完全重叠）。**回弹量由端点
  几何决定、与优化路径无关**——薄片几何是参数空间的性质而非
  某次优化运行的偶然；seed 4242 与原单次版完全一致（差 0.0000）
- **实验 1 意外发现（可能是新意点，见 §2）**：绕行通道的出平面位移
  只有 0.57%~0.78%（相对中心权重范数），但足以跨越 barrier——
  高维空间中 barrier 的"宽度"极窄，2D landscape 上看到的
  "高 loss 台地"在第三个方向上薄如纸

### 1.2 ARI"随机初始化不可连通"——证据强度：高（实验 2 确认）

- K=7 下：优化后曲线 max=1.0869（FAIL），但 5 个中间点全部压入盆地
  （0.015~0.027）——失败发生在"连向 RI 端点的最后一段"
- 解释：RI 端点本身在 barrier 之外（loss≈1.06），任何以它为端点的
  折线最后一段必须爬上台地；这与"训练找到了盆地"自洽
- **实验 2 确认（K=15 ARI，batch 10 口径）**：曲线 max=1.1015 仍 FAIL，
  13 个中间点全部入盆地（0.0154~0.0233）——加密控制点不改变结论，
  失败依旧集中在末段。**结论升级为"不可压缩的能量壁垒"（强结论）**
- 口径注：K=15 用 batch 10（8GB 显存约束，batch 50 时 K=15 激活显存
  逼近上限、2.2 小时无产出）。batch 10 端点对照：A=0.0140、RI=1.1015
  （batch 50 基线：A=0.0154、RI=1.0635、直线 max=1.0928）——两口径
  量级一致，max≈RI 端点 loss 本身，barrier 就是 RI 所在台地
- 佐证：K=15 ARI 路径 z 位移 6.5%~83.8%（AB/AC 仅 0.6~0.8%）——
  路径大幅离开 landscape 平面仍找不到低 loss 通道，壁垒是几何事实
- 健康门控数据：step10 峰值显存 3.53 GiB（限 7）、单步 0.68s（限 3s）、
  150 步全程 2.4 分钟——"K=15 硬件不可行"已被 batch 10 方案化解
- **P2b 补强（5 个 RI 重复，seed 0-4）**：5/5 全部 FAIL
  （max = 1.0573/1.0724/1.0735/1.0869/1.0745）——barrier 不是
  单点偶然，"所测 RI"的限定可以放松为"所测 5 个 RI"
- **P3 补强（ε 扫描，RI 端点松绑+范数约束）**：ε ∈ {0.5,1,2,5,10,20}%
  曲线 max = 0.783/0.499/0.268/0.214/0.829/0.742——10%/20% 非单调
  反弹。**注意：该反弹的解读已经 P3b 修正（见下方"P3 后结论表述"），
  不能直接引用"20% 邻域不可连通"**。固定端点结论不受影响
- **P1 补强（全量 197 正样本）**：ARI max=1.0968 FAIL（50 样本版
  1.0869，+1%）——口径无偏移

#### P3 后结论表述（P3b 控制实验修正版）

**初版表述（"任意 20% 邻域不可连通"）已被 P3b 撤回**——那是一次
过夜的过度解读，ε 扫描的非单调反弹里混着优化伪影成分。

ε 扫描的原始发现：可行域变大最优 loss 应单调不增，实测 10%/20%
反弹（0.829/0.742）违反单调性。两种候选解释：几何必然（邻域内
无通道）vs 优化困难（有通道但收敛不到）。**P3b 控制实验
（ε=10% 预热启动：从 ε=5% 最优解出发再优化）结果**：

- warm max=0.2450，是冷启动 0.8287 的 -70%——**反弹大部分是
  优化伪影**：更好的解存在，冷启动的 Adam 没找到
- 但 warm 后 **7 个控制点全部低 loss（0.0154~0.0302，含走满
  10% 范数的 RI 端点本身）**，曲线 max 仍 0.245——剩余反弹全部
  来自末段线性插值中点擦过 barrier 台地边缘
- ε=5% 复跑 max=0.3125（原扫描 0.2143，同 seed 差 0.098——
  GPU 非确定性在这个量级上不可忽略，见 §1.3 CV 讨论）

**修正后的结论（可写进论文的版本）**：

> 固定 RI 端点时 ARI 不可连通（K=7/K=15、5 个 RI seed 全 FAIL）。
> 允许 RI 端点在 5~10% 权重范数内移动并参与优化后，控制点序列
> 可达 0.2~0.3 量级——但仍比盆地判据 0.1 高 2~3 倍，且残余
> barrier 集中在插值段而非控制点。"随机初始化与解之间的 barrier
> 不可被折线绕过"成立，但"不可压缩"的强版本（邻域内无任何通道）
> 不成立。

**论证状态的诚实分级**：ARI 不可连通（固定端点）= 高强度、
5 RI 重复加固；端点松绑后 barrier 显著但未消除 = 中强度、
P3b 单次实验（未做多 seed）；"训练必要性"仍可论证，但措辞
必须避开"邻域内不可连通"的强宣称。

**P3c 迭代预热（回应"多预热几次能否压到盆地"）**：ε=10% 约束下
连续 5 轮（每轮 150 步、Adam 动量重置、权重延续、范数锚定原始 RI），
max 轨迹 0.954/0.407/0.504/0.726/0.549——**不收敛到盆地、也不单调**。
三个事实：①控制点 max 单调降（0.028→0.019）且全程盆内；②全部
反弹在段中点，且位置截然分层——前 4 段 0.02~0.07（盆内）、
末 2 段 0.17~0.95（擦台），5 轮全部如此；③轮间振荡与 GPU 非确定性
（§4 脆弱点 6）叠加，单轮数字不可精读。**判定：末段擦台是 ε=10%
折线参数化的固有属性——段中点不是优化变量，端点优化无法消除它；
"多预热几次就能压到盆地"被否定。** 方法边界：单 seed、段中点
离散采样（真 max 可能更高）、未做 ε=20% 迭代对照。

**P3c-2 K=15 迭代预热（分辨率 vs 几何，二选一收口）**：K=15
（14 段折线）、batch 10（健康门控 3.77 GiB / 0.77s 每步通过）、
协议同 P3c。5 轮 max 0.843/0.279/0.307/0.325/0.330——**末轮
前半段 max=0.036（盆内）、后半段 max=0.330（擦台），分层依旧**。
**判定：加密折线不消除末段擦台——插值不可压缩是几何固有，
不是 K=7 分辨率伪影。P3 链条收口。** 口径注：batch 10 与 P3c
batch 50 的 loss 绝对值不可直比，本实验只比"末段 vs 前段"的
结构（分层存在与否），该结构两口径一致。

### 1.3 运行间稳定性——实验 3 + P2a 已量化：CV=4.8%/6.9%（稳定区）

- AB K=7 三 seed（42/137/2024）优化后 max = 0.0597 / 0.0657 / 0.0630，
  mean=0.0628 ± std=0.0030，**CV=4.8%**（<10% 稳定判据线）
- **P2a 补强（10 seed）**：max 分布 0.0407~0.0490，
  mean=0.0449 ± 0.0031，**CV=6.9%**——10 倍样本量下仍 <10%，
  全部 PASS 零翻转；论文可报 single number ± std
- 全量 197 口径下三 seed CV=1.5%（0.0422/0.0435/0.0430）更稳
- 此前主实验三次运行的极差 ~30%（0.0560/0.0660/0.0730）定性为
  GPU 非确定性 + Adam 初值的联合效应；固定 opt_seed 后波动收窄一个量级，
  说明主要方差源是优化器初始化而非 CUDA 非确定性本身

## 2. 与 Garipov 2018 的差距：候选新意点

Garipov et al. 2018（Loss Surfaces, Mode Connectivity, and Fast
Ensembling of DNNs）已确立：训练好的网络间存在低 loss 连通曲线，
直线插值的 barrier 是投影错觉。我们**不能**宣称"发现 mode
connectivity"。候选新意按证据强度排序：

### 候选 a（新立住概率最高）：**barrier 的"薄片"几何**
- 实验 1 的 z 投影消融是 Garipov 论文没有的对照：把连通曲线投影回
  2D 线性子空间，loss 立即回弹 barrier 量级——定量展示
  "2D 可视化高估 barrier 的维度效应"
- 数字支撑：0.7% 的出平面位移 <-> 70 倍 loss 下降；
  2D 投影 barrier ≈1.09 vs 真实可达 max≈0.06
- 论文卖点：**对 loss landscape 可视化方法学的警示**——
  2D 切片上的 barrier 高度是方法伪影，不是优化障碍
- 风险：需查文献确认是否已有人做过"projection ablation"
  （mode connectivity + 随机 2D 投影的对照在 Fort & Scherlis 2019
  附近可能有相近结论，需查）

### 候选 b：关键点检测任务（非分类）的 barrier 结构
- Garipov 及后续工作全在分类（CIFAR/ImageNet）； OrderedKeypointLoss
  是多任务几何 loss（coverage/bbox/GP/poisson/kpt 5 项加权）
- 差异化： barrier 在结构化预测任务上的形态（5 拱 vs 分类论文的
  单峰）、以及"端点 loss≈0.015 的极低盆地"是否任务特有
- 风险：审稿人可能认为"换个任务重新画图"创新度不足

### 候选 c：ARI 不可连通 -> "训练动力学必要性"
- 若实验 2 确认 K=15 仍 FAIL：可论证"随机初始化与解之间的 barrier
  不可被折线绕过，梯度下降本身是穿越 barrier 的唯一路径"——
  与 3B 真轨迹（20ep 内沿下降方向走、seed 分离是后期慢漂移）互证
- 这是"训练为什么必要"的 loss landscape 论证，教学/答辩价值高
- 风险：RI 端点 selection 有随机性，需要多个 RI 重复（每个 ~4 分钟）
  才能宣称 general
- **P3b/P3c 后的措辞（隐含循环的自洽版本）**：预热起点本身是
  Adam 从 RI 附近搜出来的——"没有训练哪来预热起点"。训练必要性
  的承载位置从"端点自由度"移到了"起点定位 + 插值几何"两层：
  > 随机初始化与解之间存在 barrier。即使松绑端点自由度（20%），
  > 冷启动优化找不到低 loss 控制点序列；给予从训练解出发的预热
  > 起点，可找到低 loss 控制点序列，但连接它们的折线段仍不可压缩。
  > （P3c 迭代预热结果见 §1.2 P3b/P3c 段）
- 避免"唯一路径"的强版本；用"barrier 显著且不可被折线完全绕过"

**综合判断**：单独任何一条都不足以撑一篇主流期刊论文；
**a + c 组合**（可视化方法学警示 + 训练必要性论证，以关键点任务为
载体）是当前证据下最扎实的论文骨架，但体量更接近
workshop/短文或学位论文的一节。是否值得投入，取决于团队的目标
会议/期刊层级。

## 3. 审稿人三问预判（及回答现状）

### Q1：K 敏感性？折线是过参数化钻空子吗？
- 实验 2 回答：**K=15 ARI 仍 FAIL（max=1.1015），AB/AC 类比外推稳定**。
  ARI 的失败模式与 K 无关（两种 K 下中间点全部入盆地、失败全在末段），
  排除"折线分辨率不足导致 FAIL"的解释
- K=15 AB/AC 未跑（原三配对版因显存 2.2 小时无产出被叫停）；
  batch 10 方案已验证可行（健康门控 3.53 GiB / 0.68s 每步），
  若审稿人要求可补，单配对约 3~8 分钟
- 已有防线：实验 1b 的投影消融证明低 loss 是几何事实，
  不是"控制点自由度多"的拟合产物；段平滑度指标（max 跳变
  0.0086 / mean 0.0031，AB K=7）显示曲线无剧烈抖动

### Q2：GPU 非确定性影响结论吗？
- 实验 3 回答：**CV=4.8%**（三 opt_seed max = 0.0597/0.0657/0.0630，
  mean 0.0628 ± 0.0030），全部 PASS 零翻转，<10% 稳定判据线
- 论文可报 single number ± std；PASS/FAIL 判定对运行间波动不敏感

### Q3：关键点任务 vs 分类，结论可迁移吗？
- 当前回答：任务差异影响 loss 形态细节（多任务分量的相对权重），
  但 barrier 现象本身是参数空间几何，与任务无关的文献先例
  （Garipov 在 CNN、Fort 在 ResNet/VGG、档 DR 经典网络）支持迁移
- 诚实边界：我们没有第二个任务的数据；论文措辞应写
  "在结构化预测任务上首次观察"而非"普遍成立"
- 风险与机会并存（见 §2 候选 b）

## 4. 不做的风险 & 诚实清单

| 若实验揭示 | 我们的做法 |
|---|---|
| K=15 让 ARI PASS | （实际结果：仍 FAIL，此分支未触发） |
| 3 seed CV>20% | （实际 CV=4.8%，此分支未触发；论文报 single number ± std） |
| z 消融若回弹很小（<0.1） | （实际发生的是相反结果：回弹到 barrier 量级） |

**已确认的脆弱点（过夜补强后状态）**：
1. ~~RI 端点只有 1 个样本~~ **已消除（P2b）**：5 个 RI seed 全 FAIL
   （1.057~1.087）；P3 进一步显示端点松绑 20% 范数仍 FAIL——
   措辞可用"所测 5 个 RI 全部不可连通"
2. ~~50 样本子集偏差~~ **已消除（P1）**：全量 197 与 50 样本判定
   零翻转，AB/AC max 偏差 -21%（同量级、略低）、ARI +1%；
   3 seed CV 全量口径 1.5%。论文可声明"全量验证过"
3. ~~投影消融只做了 AB~~ **已消除（P0）**：AC 消融与 AB 同构
   （z 位移 0.59~0.76% vs AB 0.57~0.78%；回弹 0.41~1.09 vs
   0.31~1.09）——薄片几何不是 AB 特例。**进一步（5-seed 消融）**：
   AB/AC 各 5 opt_seed 10/10 run 判据 100% 命中，跨 seed 差异
   <0.002pp——消融结论对优化器随机性完全稳健
4. barrier 高度（直线 max≈1.09）依赖 2D 子空间方向的选择
   （seed 子空间），不同子空间 barrier 不同——这是方法学边界，
   不是 bug（**未补**：需多子空间对照，超出本轮范围）
5. **P3b 修正后新增**：ε 扫描的 10%/20% 反弹大部分是优化伪影
   （warm 启动 -70%），但 P3b 只做了 ε=10% 单点、未做多 seed 与
   ε=20% 对照；且残余 barrier 的"插值段擦台"现象只有单次观察，
   K 加密（K=15 端点松绑版）能否压掉末段中点反弹未测——
   强宣称不可用，中强度表述需注明单次实验边界
6. **P3 系列 GPU 非确定性量级警示**：ε=5% 同 seed 复跑 max 差
   0.098（0.3125 vs 0.2143），**远大于实验 3 的 CV=4.8%**——
   ε 约束让可行域内 loss 更平坦，优化器对初始化的依赖远超
   AB/AC 稳定性实验。**P3 类数字不能报单次精确值**：论文须报
   多次分布，或报量级（"0.2 附近"）并注明"单次实验，同 seed
   复跑差异可达 0.1 量级"。固定端点 ARI（5 RI、K=15）不受此
   影响——其 FAIL 判定量级为 1.05~1.10，远超波动幅度
