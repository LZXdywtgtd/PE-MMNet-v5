# 文档审查指南

> PE-MMNet v4 文档审查通用检查清单 | 每次文档更新时必读

---

## 一、审查时机

| 时机 | 说明 |
|------|------|
| 代码变更后 | 检查涉及文档是否需要同步更新 |
| 新增模型变体/损失函数 | 更新架构设计文档和API文档 |
| 新增命令行参数 | 更新用户指南和开发人员文档 |

## 二、通用审查维度

### 2.1 准确性审查（最重要）

**核心原则**：文档必须与实际代码一致。

#### 必查项

| 检查项 | 审查方法 |
|--------|----------|
| CLI 参数是否存在 | `grep -n "run_train.py --" docs/` 或在 `run_train.py` 中搜索 |
| 函数签名是否正确 | 对照 `run_train.py` / `data/dataset_multimodal.py` 等源文件 |
| 默认参数值是否正确 | 检查源代码中的默认值 |
| 函数/类名是否正确 | 对照 `models/`, `training/` 源文件 |
| 损失权重默认值是否正确 | 检查 `training/mono_loss.py` 中的默认值 |
| 硬件要求/显存占用是否合理 | 对照代码中的显存检测逻辑 |

#### 常见错误模式

- ❌ 文档写了 `--use_se` 但实际只有 `--use_coord_attn`
- ❌ 文档写了 `patience=20` 但实际默认 `patience=30`
- ❌ 文档写了 `lr=3e-4` 但实际默认 `lr=1e-3`（架构自适应调整为 `1e-4`）
- ❌ ViTYOLOFPN 描述有 `384→256` 投影但实际骨干输出直接是 256 通道
- ❌ 描述了不存在的函数/类

#### 验证命令

```bash
# 验证参数存在
grep -n "use_se\|use_coord" run_train.py

# 验证函数签名
python -c "from run_train import train_model; import inspect; print(inspect.signature(train_model))"

# 验证模型架构
python -c "from models.pe_tsnet_yolo import ViTYOLOFPN; import torch; m = ViTYOLOFPN(); print([(n, p.shape) for n, p in m.named_children()])"
```

### 2.3 一致性审查

#### 跨文档一致性

同一信息在多个文档中出现时，必须保持一致：

| 必查一致性项 | 涉及文档 |
|------------|----------|
| 默认 patience 值 | 快速配置指南、调参与算法工程指导文档、项目算法报告 |
| 默认学习率 | 用户指南、调参文档、开发人员文档 |
| 模型显存占用 | 架构设计文档、用户指南、团队协作指南 |
| 模型输入尺寸 | 架构设计文档、用户指南 |
| 任务ID命名 | 团队协作指南、开发人员文档 |
| 损失函数默认值 | 架构设计文档、调参文档 |

#### 交叉引用检查

```bash
# 验证所有 .md 链接
grep -rn "]\(" docs/ --include="*.md"

# 检查是否引用了不存在的文件
for f in docs/**/*.md; do
  links=$(grep -oP '\]\([^)]+\.md\)' "$f" | sed 's/.*\](\([^)]*\))/\1/')
  for link in $links; do
    if [[ ! -f "docs/$link" && ! -f "$(dirname $f)/$link" ]]; then
      echo "$f: broken link → $link"
    fi
  done
done
```

## 四、审查流程

### Step 1：代码审查

修改代码后，先确认需要更新的文档：

1. 新增/修改了 CLI 参数 → 更新用户指南、调参文档、开发人员文档
2. 新增/修改了模型架构 → 更新架构设计文档
3. 新增/修改了损失函数 → 更新架构设计文档、调参文档
4. 新增/修改了公开函数 → 更新API文档
5. 新增/修改了团队协作功能 → 更新团队协作指南

### Step 2：文档自检

按照本指南"二、通用审查维度"逐项检查。

### Step 3：交叉引用验证

```bash
# 检查所有 .md 文件中的链接
python -c "
import os, re
docs_dir = 'docs'
for root, dirs, files in os.walk(docs_dir):
    for f in files:
        if f.endswith('.md'):
            path = os.path.join(root, f)
            with open(path, 'r', encoding='utf-8') as fp:
                content = fp.read()
            # 找所有 .md 链接
            links = re.findall(r'\[.+?\]\((.+?\.md)\)', content)
            for link in links:
                # 解析相对路径
                base = os.path.dirname(path)
                target = os.path.normpath(os.path.join(base, link))
                if not os.path.exists(target):
                    print(f'BROKEN: {path} -> {link}')
"
```

### Step 4：运行示例

```bash
# 用户指南命令示例
python run_train.py --mode train --variant resnet18 --epochs 1

# API 文档函数验证
python -c "
from data.dataset_multimodal import create_multibatch_dataloaders
import inspect
sig = inspect.signature(create_multibatch_dataloaders)
print(sig)
"
```

## 五、常见问题速查

| 文档问题 | 根因 | 解决方案 |
|----------|------|----------|
| 参数不存在 | 文档基于旧版代码 | 对照 `run_train.py` 重新确认 |
| 默认值不对 | 未同步最新默认值 | 从源代码读取实际默认值 |
| 链接断裂 | 文件重命名后未更新引用 | 用 grep 搜索旧文件名并替换 |
| 架构描述不一致 | 不同文档由不同人维护 | 以架构设计文档为准，其他文档引用 |
| 缺少新增内容 | 审查时未对照源代码 | 必须阅读源代码后再审查 |
