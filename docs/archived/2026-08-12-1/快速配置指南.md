# 快速配置指南

> PE-MMNet v4 首次使用必读 | 10分钟快速上手

---

## 一、环境准备

### 1.1 硬件要求

| 硬件 | 最低配置 | 推荐配置 |
|------|----------|----------|
| GPU | 4GB 显存 | 8GB+ 显存 |
| 内存 | 8GB | 16GB |
| 存储 | 10GB | 20GB+ |

### 1.2 Python 环境

**要求**：Python 3.8 或更高版本

```bash
python --version
```

### 1.3 安装依赖

```bash
cd project_v4
pip install -r requirements.txt
```

核心依赖：
- `torch` - PyTorch 深度学习框架
- `timm>=0.9.0` - Swin/ViT 预训练模型库
- `scipy` - 科学计算
- `numpy`, `pandas` - 数据处理

### 1.4 验证安装

```bash
python -c "import torch; print(f'PyTorch: {torch.__version__}'); print(f'CUDA: {torch.cuda.is_available()}')"
```

## 二、数据准备

### 2.1 数据目录结构

**文件夹名称无所谓，代码会自动扫描！**

```
data_root/
├── 实验A/
│   ├── 温度/d001.png, d002.png, ...     # 温度场图像（必须）
│   ├── 应力/d001.png, d002.png, ...     # 应力场图像（必须）
│   ├── 表格/Table_表面最大值.csv          # 标签数据（可选）
│   └── d_hist/d001.png, d002.png, ...   # 分割掩膜（可选）
└── 实验B/
    ├── 温度/x001.png, x002.png, ...
    └── 应力/x001.png, x002.png, ...
```

| 文件夹 | 必须 | 说明 |
|--------|------|------|
| `温度/` | 必须 | PNG 灰度图像 |
| `应力/` | 必须 | PNG 灰度图像 |
| `表格/` | 可选 | CSV 标签文件 |
| `d_hist/` | 可选 | 分割掩膜图像 |

### 2.2 配置数据路径

**自动配置（推荐）**：
首次运行 `train_launcher.py` 会自动提示配置。

**手动配置**：
创建 `config.json`：

```json
{
  "data_root": "D:\\你的路径\\参考输入"
}
```

## 三、快速开始

### 3.1 团队协作（推荐新手）

最简单的训练方式：

```bash
python team_train.py
```

菜单中选择任务编号即可开始训练。

### 3.2 交互式启动

```bash
python train_launcher.py
```

图形菜单，可选变体、参数、批次。

### 3.3 直接训练

```bash
# 基线模型（推荐首次使用）
python run_train.py --mode train --variant resnet18 --epochs 150

# Swin-YOLO（需要预训练权重，默认 lr=1e-4）
python run_train.py --mode train --variant swin_yolo --epochs 150

# ViT-YOLO（需要预训练权重，默认 lr=1e-4）
python run_train.py --mode train --variant vit_yolo --epochs 150

# DETR（需要预训练权重，默认 lr=1e-4）
python run_train.py --mode train --variant detr --epochs 150

# PatchTST时序骨干（需要预训练权重，默认 lr=1e-4）
python run_train.py --mode train --variant swin_yolo_patchtst --epochs 150
```

## 四、模型变体选择

| 变体 | 架构 | 显存占用 | 推荐场景 |
|------|------|----------|----------|
| `resnet18` | ResNet-18 + Cross-Attention | ~2GB | 新手首选，快速验证 |
| `swin_yolo` | Swin-Tiny + YOLO-FPN + Cross-Attention | ~4GB | 空间定位精度要求高 |
| `vit_yolo` | ViT-Small + YOLO-FPN + Cross-Attention | ~3GB | 全局注意力需求 |
| `swin_yolo_patchtst` | Swin-Tiny + YOLO-FPN + PatchTST | ~4GB | 长程时序依赖 |
| `detr` | ResNet-18 + Transformer + Cross-Attention | ~5GB | 全局上下文感知 |
| 消融变体 | `1d_only`, `2d_only`, `concat`, `add`, `cross_attn` | ~1-2GB | 消融实验 |

## 五、高级参数

### 5.1 融合方式

```bash
# 交叉注意力融合（默认）
python run_train.py --variant resnet18 --fusion cross_attn

# 门控融合（温度/应力分治）
python run_train.py --variant resnet18 --fusion gated
```

### 5.2 注意力模块

```bash
# 坐标注意力（保留位置信息，所有变体均支持）
python run_train.py --variant resnet18 --use_coord_attn
python run_train.py --variant swin_yolo --use_coord_attn
```

### 5.3 分阶段训练

```bash
# 先短序列预训练，再长序列微调
python run_train.py --variant resnet18 --staged_train --epochs 150

# 自定义短序列批次
python run_train.py --variant resnet18 --staged_train --short_batches 单次扫描 参数化扫描1
```

### 5.4 数据增强

```bash
# ThermalCutMix（物理安全版，仅作用于温度通道）
python run_train.py --variant resnet18 --aug_cutmix_prob 0.3
```

### 5.5 三通道时序输入

```bash
# 使用 [初始温度, 当前温度, 温度变化率] 三通道
python run_train.py --variant resnet18 --triple_channel
```

### 5.6 时间偏移预测

```bash
# 预测 1 步后（0.05s后）的标签
python run_train.py --variant resnet18 --predict_offset 1

# 预测 2 步后（0.1s后）的标签
python run_train.py --variant resnet18 --predict_offset 2
```

### 5.7 等值线预处理

```bash
# 对参数化扫描4启用等值线去除预处理
python run_train.py --variant resnet18 --remove_contours
```

### 5.8 禁用数据批次

```bash
# 禁用指定批次（可多个）
python run_train.py --variant resnet18 --disable_batch 参数化扫描4
```

## 六、显存配置

系统自动检测显存并选择配置：

| 空闲显存 | 图像尺寸 | 批次大小 | FP16 |
|----------|----------|----------|------|
| ≥10 GB | 512 | 16 | 是 |
| 6-10 GB | 512 | 8 | 是 |
| 4-6 GB | 384 | 8 | 是 |
| <4 GB | 256 | 4 | 否 |

**手动指定**：

```bash
python run_train.py --image_size 384 --batch_size 4
```

## 七、常见问题

| 问题 | 解决方案 |
|------|----------|
| `CUDA: False` | `pip install torch --index-url https://download.pytorch.org/whl/cu118` |
| "未找到数据批次" | 检查 `config.json` 中的 `data_root` |
| Loss 是 NaN | 使用 `--lr 1e-4` |
| 显存不足 | `--image_size 256 --batch_size 4` |
| 预训练权重下载慢 | `set HF_ENDPOINT=https://hf-mirror.com` |

### 7.1 预训练权重问题（swin_yolo/vit_yolo/detr）

这些变体需要从 HuggingFace 下载预训练权重。

**方法1：设置镜像站（推荐）**

```bash
# Windows
set HF_ENDPOINT=https://hf-mirror.com

# Linux/Mac
export HF_ENDPOINT=https://hf-mirror.com
```

**方法2：使用 resnet18 变体（无需预训练权重）**

```bash
python run_train.py --variant resnet18 --epochs 3
```

## 八、训练监控

### 8.1 实时 ETA

每10轮显示训练进度盒子（Valid行超长时会分两行显示）：
```
╔════════════════════════════════════════════════════════════════════╗
║ Epoch 15/150 | Best: 12 | Progress: [████████░░░░░░░░] 10%  ║
╠════════════════════════════════════════════════════════════════════╣
║ Train | Loss: 0.4562 | LR: 3.00e-04 | Time: 1.3s          ║
╠════════════════════════════════════════════════════════════════════╣
║ Valid | R2: 0.8756 (Δ+0.0234) | RMSE: 0.1423 (Δ-0.0012)   ║
║       | MAE: 0.1023 (Δ-0.0056) | 违反率: 38.2% (Δ-2.1%)  ║
╠════════════════════════════════════════════════════════════════════╣
║ System| EMA: 1.3s/epoch | ETA: 2m55s | 完成: 14:32 ±0.2s   ║
╚════════════════════════════════════════════════════════════════════╝
```

说明：
- Valid行分两行显示时，`(Δ±value)` 为相对上轮的改善值（+表示改善）
- System行显示置信区间（5轮后开始计算）

### 8.2 检查点保存

自动保存在 `checkpoints/{variant}/` 目录：
- 文件名格式：`{variant}_{task}_off{offset}_best.pt`
- 示例：`resnet18_detection_off0_best.pt`
- 元数据包含 `task_id`, `epoch`, `timestamp`, `config`（用于签名校验）

## 九、团队协作

### 9.1 组员操作

1. 接收协调者发来的 `tasks/` 文件夹
2. 放入 `project_v4/` 目录
3. 运行 `python team_train.py`
4. 选择任务编号开始训练

### 9.2 检查点导入

将队友的 `.pt` 检查点复制到 `checkpoints/` 目录，下次运行自动识别。

**命令行导入**（也可以手动）：
```bash
python team_train.py --import
```

### 9.3 自动执行

```bash
# 自动执行所有可执行任务
python team_train.py --auto

# 强制执行（包括硬件警告任务）
python team_train.py --auto --force
```
