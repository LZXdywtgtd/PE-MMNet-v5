# 调参与算法工程指导文档

> PE-MMNet v4 损失函数配置与调参指南

---

## 一、损失函数架构

### 1.1 基础模型 (resnet18)

```
L_total = λ_mse · L_mse + λ_mono · L_mono + λ_loc · L_loc + λ_conf · L_conf
```

| 损失分量 | 默认权重 | 说明 |
|----------|----------|------|
| L_mse | 1.0 | 密度MSE损失 |
| L_mono | 0.1 | 单调性约束 |
| L_loc | 1.0 | 定位损失(DIoU) |
| L_conf | 1.0 | 置信度损失(BCE) |

### 1.2 YOLO变体 (swin_yolo, vit_yolo, swin_yolo_patchtst)

```
L_total = λ_box · L_box + λ_conf · L_conf + λ_mono · L_mono
```

### 1.3 DETR变体

```
L_total = λ_bbox · L_bbox + λ_conf · L_conf + λ_mono · L_mono + 0.5·L_supervise
```

其中 `L_bbox` 使用 Smooth L1 Loss，`L_conf` 使用 BCE Loss，`L_supervise` 是经 Hungarian 匹配后选出的最佳 query 经融合层输出的监督损失。

---

## 二、各损失详解

### L_mse - 密度预测损失

直接优化裂纹密度预测精度（resnet18 变体）。

```bash
# 密度预测不准 → 增大
python run_train.py --lambda_mse 2.0
```

### L_mono - 单调性约束

保证物理自洽性（裂纹不可逆），所有变体均支持。

```bash
# 违反率高 → 增大
python run_train.py --lambda_mono 0.3
```

### L_loc - 定位损失

DIoU Loss，优化边界框定位精度（resnet18 变体）。

```bash
# mIoU低 → 增大
python run_train.py --lambda_loc 2.0
```

### L_conf - 置信度损失

BCE Loss，优化裂纹存在概率预测。

## 三、调参场景

| 场景 | 指标问题 | 调参建议 |
|------|----------|----------|
| 密度预测不准 | R² 低 | `--lambda_mse 2.0`（仅 resnet18） |
| 物理违反率高 | >60% | `--lambda_mono 0.3` |
| 位置预测不准 | mIoU 低 | `--lambda_loc 2.0`（仅 resnet18） |

**调参流程**：
1. 先用默认配置观察 baseline
2. 根据评估结果针对性调整
3. 微调示例：`--lambda_mse 1.5 --lambda_mono 0.2`

## 四、学习率调参

| 架构 | 默认学习率 | 说明 |
|------|------------|------|
| ResNet18 | 1e-3 | 默认值，架构自适应可能调整 |
| ViT / Swin / YOLO / DETR | 1e-4 | 架构自适应降至此值 |

> `run_train.py` 统一默认 lr=1e-4（`--lr` 参数默认值），`get_arch_specific_config()` 会根据骨干类型微调。ResNet18 自动升至 1e-3，ViT/Swin 等精细网络保持 1e-4。

```bash
# 手动指定学习率（推荐用于所有精细网络）
python run_train.py --lr 1e-4

# 提高学习率（更快但可能不稳定）
python run_train.py --lr 5e-4
```

## 五、高级优化参数

### 5.1 坐标注意力

保留位置信息的注意力机制（仅支持 `resnet18` 等带 `branch_2d` 的变体）。

```bash
python run_train.py --variant resnet18 --use_coord_attn
```

### 5.2 分阶段训练

先短序列预训练，再长序列微调。

```bash
python run_train.py --variant resnet18 --staged_train --epochs 150
```

### 5.3 三通道时序输入

使用 [初始温度, 当前温度, 温度变化率] 三通道。

```bash
python run_train.py --variant resnet18 --triple_channel --epochs 150
```

### 5.4 ThermalCutMix

物理安全增强（仅混合温度通道）。

```bash
python run_train.py --aug_cutmix_prob 0.3
```

### 5.5 密度一致性损失

邻域网格密度平滑约束，结合 MSE 密度损失和一致性损失。

```python
from training.mono_loss import CombinedDensityLoss

criterion = CombinedDensityLoss(
    lambda_mse=1.0,           # MSE密度损失权重
    lambda_consistency=0.5,   # 一致性损失权重
    grid_size=16,
    neighbor_range=1
)
```

### 5.6 坐标注意力（通用）

所有变体均支持 `--use_coord_attn`，注入坐标注意力增强空间位置感知：

```bash
python run_train.py --variant resnet18 --use_coord_attn
python run_train.py --variant swin_yolo --use_coord_attn
```

## 六、其他关键参数

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `--dropout` | 0.2 | 防止过拟合 |
| `--patience` | 30 | 早停耐心值（连续N轮无改善则停止） |
| `--image_size` | 自动 | 显存自适应（256~1024） |
| `--predict_offset` | 0 | 时间偏移量（预测未来步数） |
| `--feature_len` | 300 | 1D序列长度 |
| `--seq_interp_mode` | interpolate | 序列插值模式（interpolate/pool） |
| `--no_fp16` | False | 禁用 FP16 混合精度 |
| `--staged_train` | False | 启用分阶段训练 |
| `--triple_channel` | False | 三通道时序输入 |
| `--aug_cutmix_prob` | 0.0 | ThermalCutMix 启用概率 |

## 七、常见问题

| 问题 | 解决方案 |
|------|----------|
| Loss 是 NaN | `--lr 1e-4` |
| 违反率高 | `--lambda_mono 0.3` |
| 密度预测偏低 | 检查标签或 `--lambda_mse 1.5` |
| 显存不足 | `--image_size 256 --batch_size 4` |
