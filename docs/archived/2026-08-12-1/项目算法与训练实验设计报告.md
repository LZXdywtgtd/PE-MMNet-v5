# 项目算法与训练实验设计报告

> PE-MMNet v4 多模态裂纹预测系统

---

## 一、问题背景

日用陶瓷在热震过程中会产生裂纹，需要实时预测裂纹的位置、尺寸和密度。

**物理约束**：
- 裂纹密度随温度下降单调递增（格里菲斯断裂准则）
- 裂纹不可逆
- 裂纹位置与应力集中区域相关

---

## 二、算法设计

### 2.1 非对称双分支架构

```
输入
├── 1D 分支：温度时序 (batch, 300)
│   └── Micro + Macro 1D-CNN + Self-Attention → 64 维
└── 2D 分支：温度场+应力场 (batch, 2, H, W)
    └── 骨干网络 → 512 维特征

融合：Cross-Attention → 输出Head
输出：检测向量 / 分割掩膜
```

### 2.2 模型变体

| 变体 | 2D骨干 | 检测方式 | 特点 | 性能等级 |
|------|--------|----------|------|----------|
| `resnet18` | ResNet-18 | MLP回归 | 默认基线 | L1 |
| `swin_yolo` | Swin-Tiny | YOLO网格回归 | 空间定位强 | L1+ |
| `vit_yolo` | ViT-Small | YOLO网格回归 | 全局注意力 | L1 |
| `swin_yolo_patchtst` | Swin-Tiny + PatchTST | YOLO网格回归 | 长程时序依赖 | L1+ |
| `detr` | ResNet-18 | Transformer | 全局感知 | L1+ |

### 2.3 Cross-Attention 融合

双向交叉注意力实现"时域驱动力 × 空间薄弱位置"的物理耦合：

```
方向1（图像查询温度）：Q_2d → K_1d, V_1d
方向2（温度查询图像）：Q_1d → K_2d, V_2d
融合：concat → 输出Head
```

## 三、损失函数设计

### 3.1 基础模型

```
L_total = λ_mse·L_mse + λ_mono·L_mono + λ_loc·L_loc + λ_conf·L_conf
```

| 损失 | 物理原理 | 默认权重 |
|------|----------|----------|
| L_mse | 密度预测误差 | 1.0 |
| L_mono | 格里菲斯断裂准则 | 0.1 |
| L_loc | DIoU定位 | 1.0 |
| L_conf | BCE置信度 | 1.0 |

### 3.2 单调性损失

```python
L_mono = Σ max(0, pred[i+1] - pred[i]) / (n-1)
```

仅当密度下降时计算惩罚，保证物理自洽性。

## 四、高级优化

### 4.1 分阶段训练

先在短序列数据上预训练，再在全部数据上微调。

### 4.2 门控多模态融合

温度/应力分治策略，通过门控机制自适应选择融合权重。

### 4.3 ThermalCutMix

物理安全增强：仅混合温度通道，应力通道保持不变。

## 五、训练策略

### 5.1 显存自适应

| 空闲显存 | 图像尺寸 | 批次大小 | FP16 |
|----------|----------|----------|------|
| ≥10 GB | 512 | 16 | ✅ |
| 6-10 GB | 512 | 8 | ✅ |
| 4-6 GB | 384 | 8 | ✅ |
| <4 GB | 256 | 4 | ❌ |

### 5.2 早停机制

patience = 30：连续 30 epoch 验证损失无改善则停止。
