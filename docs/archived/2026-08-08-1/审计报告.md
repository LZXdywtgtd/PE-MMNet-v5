### A组共性问题（跨变体）

| ID | 严重程度 | 位置 | 问题描述 | 影响变体 |
|----|----------|------|----------|----------|
| **G-1** | 🟡 低 | `dataset_multimodal.py:577-594` | `PhysicalSafeTransform1D` 对三通道输入处理错误：`len(seq)` 返回通道数而非序列长度，噪声被加到通道维度 | 所有 triple_channel 变体 |

### G-1 详细

**位置**：`data/dataset_multimodal.py:577-594`

```python
class PhysicalSafeTransform1D:
    def __call__(self, seq):
        seq = seq.copy()
        # 问题：len(seq) 对 (3, 300) 返回 3，而非 300
        if np.random.random() < 0.3:
            seq_len = len(seq)   # ❌ 应为 seq.shape[-1]
            mask_start = np.random.randint(0, seq_len - mask_len)
            seq[mask_start:mask_start + mask_len] = 0
        seq += np.random.randn(len(seq)).astype(np.float32) * self.noise_std  # ❌
        return seq
```

**触发条件**：`--triple_channel` + `augment=True`
**修复方向**：在 `seq.ndim > 1` 时对 `seq[-1]` 维度加噪

### G-2 详细

### A组特有/严重问题

#### ⚠️ S-1：swin_yolo / swin_yolo_patchtst assigner 网格尺寸不匹配

**位置**：`run_train.py:1191-1195` + `pe_tsnet_yolo.py:346-347, 577-578`

Swin-YOLO 中存在两组网格尺寸定义：

| 参数 | 来源 | 计算公式 | image_size=256 时 |
|------|------|----------|-------------------|
| `actual_grid_size` | `SwinYOLOFPN.__init__` | `image_size // 32` | 8 → 64 网格 |
| `grid_size` | 固定参数 | 硬编码 16 | 16 → 256 网格 |

**根本原因**：

```python
# pe_tsnet_yolo.py:346-347
self.actual_grid_size = image_size // 32  # 实际特征图网格数
self.actual_num_grids = self.actual_grid_size ** 2  # 64

# YOLOFPNHead 内部用 grid_size=16 生成 256 个预测
# 但实际特征图只有 8×8=64 个位置
```

assigner 用的是 `actual_grid_size`（传递给 YOLOTargetAssigner）：

```python
# run_train.py:1191-1195
if variant_key in ['swin_yolo', 'swin_yolo_patchtst']:
    actual_grid_size = model.actual_grid_size  # ⚠️ 用了 actual_grid_size = 8
else:
    actual_grid_size = 16
assigner = YOLOTargetAssigner(grid_size=actual_grid_size, nearby_range=2)
```

assigner 基于 8×8=64 网格分配目标，但模型输出 16×16=256 网格。

**后果**：
- 目标被分配到错误的网格索引（assigner 分配的索引基于 64 网格，但模型输出 256 网格）
- `positive_mask` 与实际正样本位置不匹配
- 损失计算可能集中在错误区域

**修复建议**：assigner 应使用 `model.grid_size`（固定 16）而非 `model.actual_grid_size`。

#### S-2：swin_yolo / swin_yolo_patchtst / vit_yolo eval 模式验证损失异常

**位置**：`run_train.py:1529-1537`

eval 模式将单预测 (B,6) 广播为 (B,N,6)，所有网格标记为正样本，损失值不反映真实训练损失。

#### D-1：detr PositionalEncoding2D 固定初始化 vs 动态特征图

**位置**：`pe_tsnet_detr.py:276-290`

`DETRStyle` 初始化时 `self.feat_size = 8`（硬编码），但 ResNet18 最终特征图与 `image_size` 相关。

严重程度低，功能正确，仅有冗余 resize。

#### P-1：swin_yolo_patchtst PatchTST1D 不支持三通道输入

**位置**：`pe_tsnet_patchtst.py:108-146`

`PatchTST1D` 只接受 `(B, seq_len)`，不支持 `(B, 3, seq_len)` triple_channel 格式。

触发条件：`--variant swin_yolo_patchtst --triple_channel`

#### V-1：vit_yolo ViTYOLOBackbone2D 固定 16×16 输出

**位置**：`pe_tsnet_yolo.py:119-188`

无论 `image_size` 是多少，骨干网络都输出固定的 16×16 特征图。

严重程度低，设计意图明确（16×16=256 网格与 YOLO head 匹配）。

## C组：组合优化审计框架

> C组为多个flag同时启用的组合。审计重点：**flag之间的交互是否会产生冲突或冗余**。

| 组合 | 包含flags | 潜在冲突点 |

### 通用组合审计检查项

- [ ] 任意两个 flag 的代码路径是否在同一个函数内有交叉判断

- [ ] 损失函数分支是否能覆盖所有 flag 组合
- [ ] `eval_checkpoint` 是否能正确读取所有 flag 配置并重建模型

## 附录：维度追踪规范

```
输入: x_1d (B, seq_len), x_2d (B, C, H, W)
  ↓ backbone_2d
feat_2d: (B, dim_2d) 或多尺度特征列表
  ↓ backbone_1d
feat_1d: (B, dim_1d)
  ↓ fusion
fused: (B, fused_dim)
  ↓ output_head
output: (B, 6) 或 (B, N, 6) 或 (mask, detection) 元组
```

必须验证：`fused_dim == output_head.input_dim`
