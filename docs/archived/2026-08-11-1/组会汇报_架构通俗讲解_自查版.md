## 一、5 个变体通俗讲解

### 1. resnet18（最简单基线）

**是什么**：经典卷积神经网络（CNN），2015 年微软提出。"18"指 18 层。**所有消融实验的基准锚点**，B 组 5 个优化策略全在它身上测。

**怎么搞的**：
- 输入 2D 图像（512×512×2 通道：温度场+应力场）
- ResNet-18 提取空间特征 → 512 维向量
- 同时 1D 时序（300 步）经 Micro/Macro 双尺度 CNN + MHA → 64 维向量
- Cross-Attention 融合（512 维 2D 作 Q，64 维 1D 作 K/V）
- MultiTaskHead 输出 6 维检测向量 [x, y, l, w, conf, density]

**原理（为什么这样设计）**：
- 残差块 = 2-3 个卷积 + 跨层直连（输入直接加到输出）
- 残差学习：H(x) = F(x) + x，学 F(x) = H(x) - x 比直接学 H(x) 容易
- 解决"网络越深越难训练"的退化问题
- Cross-Attention 让 2D 空间特征主动"问" 1D 时序"我对应的演化信息是啥"

**作用**：本项目最简单变体（~2GB 显存），作为 B 组所有优化的 baseline；也是和 5 个变体对比的"最朴素基线"。

---

### 2. vit_yolo（全局注意力 + 网格检测）

**是什么**：2D 骨干换成 ViT-Small（全局 Transformer），检测头换成 YOLO 网格的组合。验证"全局注意力骨干 + 密集网格检测"搭配效果。

**怎么搞的**：
- 2D 图像 → ViT-Small 切 16×16 patch → 全局自注意力 → 多尺度特征
- 1D 时序 → CNN+Attention → 64 维
- ViT 输出 16×16 网格 → YOLO-FPN 头 → 每网格预测 6 维（共 256 网格）
- 训练时所有网格都有监督；推理时取 conf 最高网格

**原理（为什么这样设计）**：
- ViT 用全局自注意力替代 CNN 局部卷积，能捕捉"图像远距离像素关联"
- 但 ViT 固定 224×224 输入，所以加了 `input_resize` 层（Conv2d 2→3 + 512→224 双线性插值）
- actual_grid_size 动态计算：`max(16, (image_size//32 // 4) * 4)`，确保和 YOLO 头匹配

**作用**：与 swin_yolo（窗口注意力）做对比，验证"全局 vs 局部"哪种注意力更适合本任务。

---

### 3. swin_yolo（窗口注意力 + 网格检测）★ 推荐基线

**是什么**：2D 骨干用 Swin-Tiny（窗口 Transformer），检测头用 YOLO 网格。**项目推荐基线**，多尺度特性 + 检测范式天然匹配。

**怎么搞的**：
- 2D 图像 → Swin-Tiny 切 4×4 patch → 4 个 stage 逐步下采样（1/4, 1/8, 1/16, 1/32）
- 每个 stage 内部用 7×7 滑动窗口自注意力（窗口内 + shifted window 跨窗口）
- 多尺度特征 → FPN 融合 → 16×16 网格 → YOLO 头 → 256 网格预测
- 1D 时序 → CNN+Attention → 64 维 → 融合

**原理（为什么这样设计）**：
- 窗口自注意力计算量 = O(window² × num_windows) 远小于全局 O(N²)，显存友好
- shifted window 让相邻窗口交换信息，避免"信息孤岛"
- 多尺度特征金字塔（FPN）和密集检测天然匹配（小目标用高分辨率，大目标用低分辨率）
- 16×16=256 网格让每个网格负责原图 32×32 像素，定位精细

**作用**：swin_yolo_patchtst 和 detr 都基于它的范式（Swin+YOLO 基础），是这个项目的"主力架构候选"。

---

### 4. detr（端到端全局检测）— A4_long 跑中

**是什么**：Detection Transformer，端到端检测范式。**抛弃了 anchor 和 NMS**，用 100 个 Object Query 全局检索。150 epoch 长训探索性能天花板。

**怎么搞的**：
- 2D 图像 → ResNet-18（设 spatial=True 输出 8×8 空间特征） → TransformerEncoder 6 层
- DETRDecoder 接收 100 个 Object Query，每个 query 输出 [x, y, l, w, conf, density] 6 维
- 训练时用匈牙利匹配算法把 100 个 query 与 GT 一一对应
- 推理时取 conf 最高 query 的输出

**原理（为什么这样设计）**：
- **Hungarian 匹配**：解决"100 个预测对应 N 个 GT"的最优分配问题（运筹学经典算法）
- 端到端：不需要 NMS（非极大值抑制）、不需要 anchor 预设、不需要先验
- 全局上下文：每个 query 都能看到全图所有 patch，捕捉长距离空间依赖
- 慢收敛：DETR 论文报告 500 epoch 才收敛，我们 150 epoch + 1e-4 LR 是"经济版"

**作用**：与 YOLO 范式形成**anchor-free vs anchor-based**的对比；适合裂纹"跨区域扩展"场景；A4_long 长训看性能天花板。

---

### 5. swin_yolo_patchtst（PatchTST 时序升级版）

**是什么**：在 swin_yolo 基础上，**仅 1D 时序骨干**从 CNN+Attention 升级为 PatchTST。其他完全不变，做"单变量"消融。

**怎么搞的**：
- 2D 路径和 swin_yolo 完全一样（Swin-Tiny + YOLO-FPN）
- 1D 路径换 PatchTST：300 步时序切 30 个 patch（每个 10 步）→ 线性投影 64 维 → 位置编码 → Transformer Encoder 2 层 4 头
- 融合 + YOLO 头照旧

**原理（为什么这样设计）**：
- PatchTST 把"步间"关联改为"块间"关联：相邻 10 步有强相关性，先聚成块更合理
- 降低计算量：300 步 → 30 patch（10 倍减少）
- Transformer 能学"块间"长距离依赖，捕捉"前期萌生→后期扩展"累积过程
- 唯一变量就是时序骨干，方便和 swin_yolo 直接对比

**作用**：验证"更复杂的时序建模"对整体精度的边际收益。如果提升大 → PatchTST 是更优的时序骨干。

## 二、模块化组件通俗讲解

### A. 1D 时序骨干

#### A.1 CNN+Attention（基线）

**是什么**：双尺度 1D-CNN + 多头注意力的组合。本项目时序基线。

**怎么搞的**：
- 输入 300 步温度时序
- Micro1DCNN（小卷积核 3）捕捉局部突变（如温度骤降）
- Macro1DCNN（大卷积核 15）捕捉全局趋势（如整体冷却）
- 两条路各输出 32 维
- MHA（多头注意力）融合两路 → 64 维

**原理**：
- 双尺度思想：CNN 卷积核越大感受野越大，3 步看局部，15 步看整体
- 注意力融合：让网络学"什么时候局部重要、什么时候全局重要"
- 轻量：300 步的中短序列够用

**作用**：作为 A1-A4 的时序骨干基线；和 PatchTST（A5）对比。

#### A.2 PatchTST（进阶时序）

**是什么**：分块 Transformer 时序模型，2023 年时序预测 SOTA。

**怎么搞的**：
- 300 步时序 → 切 30 个 patch（每个 10 步）
- 每个 patch 展平 → 线性投影 64 维
- 加位置编码（patch 必须有位置）
- Transformer Encoder 2 层 4 头
- 输出 64 维

**原理**：
- 相邻时间步有强相关性，切成块让模型学"块间"关联
- 计算量降低：300 步 → 30 patch（10 倍）
- Transformer 自注意力：30 patch 仍能 attention 整序列，保留长距离依赖

**作用**：替换 CNN+Attention，验证更强时序建模的边际收益。

---

### B. 2D 空间骨干

#### B.1 ResNet-18

**是什么**：经典 CNN，2015 年 ImageNet 冠军。18 层残差网络。

**怎么搞的**：图像 → 卷积提取低级特征（边缘/纹理）→ 深层卷积提取高级语义（部件/整体）→ 残差连接（输入+输出）→ 全局平均池化 → 512 维。

**原理**：残差学习 H(x)=F(x)+x，学残差 F(x) 比直接学映射 H(x) 容易，解决"深层网络退化"问题。

**作用**：resnet18 变体的骨干；B 组所有优化的基准。

#### B.2 ViT-Small

**是什么**：Vision Transformer 轻量版，2020 年 Google 提出。

**怎么搞的**：图像切 16×16 patch → 展平 → 线性投影 768 维 → 加位置编码 → Transformer Encoder（全局自注意力）→ 输出特征图。

**原理**：每个 patch 能看到所有其他 patch，捕捉长距离依赖；ImageNet 21k 预训练后才有效。

**作用**：vit_yolo 骨干；和 Swin-Tiny 对比"全局 vs 局部"。

#### B.3 Swin-Tiny

**是什么**：Swin Transformer 轻量版，2021 年微软。

**怎么搞的**：4×4 patch → 4 个 stage 逐步下采样 → 每 stage 7×7 窗口自注意力 → shifted window 跨窗口连接 → 多尺度特征金字塔。

**原理**：窗口注意力计算量小（O(N) vs O(N²)）；shifted window 避免信息孤岛；多尺度 + FPN 和检测任务天然匹配。

**作用**：swin_yolo、swin_yolo_patchtst、detr 的 2D 骨干（detr 是 ResNet-18+Transformer 编码器）。

---

### C. 检测头

#### C.1 单点回归头（resnet18 用）

**是什么**：把融合特征压成一个向量，FC 层直接输出 6 维。

**原理**：结构最简单，相当于"直接给最终答案"；缺点是空间监督弱，定位精度上限低。

**作用**：基线检测范式。

#### C.2 YOLO-FPN 网格头（swin_yolo / vit_yolo / swin_yolo_patchtst 用）

**是什么**：YOLO 风格密集预测。16×16=256 个网格，每网格独立预测 6 维。

**怎么搞的**：
- 多尺度特征 → FPN 融合 → 16×16 网格
- 每网格预测 [x, y, l, w, conf, density]
- 训练时所有 256 网格都有监督
- 推理时取 conf 最高网格

**原理**：密集监督 = 每个区域都有"答题"训练；空间定位天然好。

**作用**：3 个 YOLO 变体的检测头。

#### C.3 DETR 解码器头（detr 用）

**是什么**：100 个 Object Query + Transformer Decoder。

**怎么搞的**：
- 100 个 query 通过 cross-attention 在全局特征中检索
- 每个 query 输出 6 维检测
- 训练时匈牙利匹配 query 和 GT 一一对应

**原理**：100 个"提问者"各自问不同问题；Hungarian 匹配保证最优分配；端到端不需要 NMS。

**作用**：detr 变体的检测头。

---

### D. 融合策略

#### D.1 Cross-Attention（默认）

**是什么**：标准注意力机制。2D 空间特征作 Q，1D 时序特征作 K/V。

**怎么搞的**：
- 2D 特征（512 维）投影为 Q
- 1D 特征（64 维）投影为 K 和 V
- attention = softmax(QK^T/sqrt(d))V
- 输出 576 维融合特征

**原理**：Q 决定"问什么"（空间位置），K/V 提供"答案"（时序序列）；自适应关联。

**作用**：默认融合策略；空间为主、时序为辅。

#### D.2 Gated Fusion（B1 门控融合）

**是什么**：可学习的门控机制，2D 和 1D 各自乘权重再相加。

**怎么搞的**：
- gate_2d = sigmoid(W_2d · 2D)
- gate_1d = sigmoid(W_1d · 1D)
- output = gate_2d × 2D + gate_1d × 1D

**原理**：门控 = 自动调节阀；模型自己学"现在该更信 2D 还是 1D"（早期时序重要，扩展期空间重要）。

**作用**：B1 消融实验，对照 Cross-Attention。

---

### E. 注意力增强

#### E.1 CoordAtt 坐标注意力（B2 原创改进）

**是什么**：轻量化注意力，**同时编码通道和空间坐标**。

**怎么搞的**：
- 特征图分两路：
  - X Avg Pool：H 方向平均 → (1, W, C)
  - Y Avg Pool：W 方向平均 → (H, 1, C)
- 两路 concat → 卷积 → 拆成 H attention 和 W attention
- sigmoid 归一化 → 与原特征相乘

**原理**：
- 通道注意力（SE/ECA）只关注"哪个通道重要"，**丢失位置**
- CoordAtt 把 H 和 W 方向分开编码，**保留位置信息**
- 轻量：只增加 2 个 1D 池化 + 1 个 conv

**作用**：增强裂纹**位置**感知；**本项目唯一原创改进点**；比 SE/ECA 强。

---

### F. 训练优化策略

#### F.1 分阶段训练（B3）

**是什么**：借鉴"课程学习"，先短序列预训练，再全序列微调。

**怎么搞的**：
- Phase 1：前 100 步短序列训练 5-10 epoch
- Phase 2：冻结骨干，全 300 步微调剩余 epoch
- LR 分段：Phase 1 用 1e-3，Phase 2 用 1e-4

**原理**：先学简单（短序列），再学难（长序列），降低初始学习难度。

**作用**：B3 消融，提升泛化性能，缓解过拟合。

#### F.2 三通道输入（B4）

**是什么**：把单通道温度扩展为 3 通道："初始温度 + 当前温度 + 变化率"。

**怎么搞的**：
- 通道 0：第 0 步温度（常量）
- 通道 1：当前步温度
- 通道 2：(t - t-1) 差分（变化率）

**原理**：显式特征 = 模型学习更轻松；类似 feature engineering，把隐含特征显式化。

**作用**：B4 消融，降低学习难度。

#### F.3 ThermalCutMix（B5 物理安全数据增强）

**是什么**：借鉴 CutMix 但只混叠温度通道，应力场保持不变。

**怎么搞的**：
- 随机选样本 A 和 B
- 温度通道：mix = A × mask + B × (1-mask)
- 应力通道：保持 A 不变
- 标签按 mix 区域混合

**原理**：普通 CutMix 混所有通道会破坏应力场物理连续性；只混温度保持物理合理性。

**作用**：B5 消融，扩充数据多样性 + 物理安全。

## 三、关键参数通俗解释（应对细节追问）

### LR = 1e-4 为什么？

**通俗版**：学习率 = 模型每一步"学多少"。1e-4 是实测稳定值。YOLO/DETR 是 Transformer 结构，对学习率**极度敏感**——1e-3 必崩（NaN），1e-4 稳定。

**技术解释**：AdamW 优化器，weight_decay=0.01；CosineAnnealingLR 调度器从 1e-4 余弦降到 1e-6。

### FP16 是什么？

**通俗版**：模型用"半精度"（16 位浮点）训练，**显存省一半 + 速度提升 2 倍**，精度几乎不损失。

**技术解释**：混合精度训练，保留 FP32 权重做更新，前向用 FP16 算图。

**为什么需要**：8.5GB 显存下，FP32 跑 batch=4 都不够；FP16 能跑 batch=8。

### 配置签名校验（v4.6.5）

**通俗版**：14 个关键字段的"指纹"，训练前检查"这次配置和上次是不是兼容"。不匹配就强制重训 + 备份旧检查点。

**技术解释**：14 字段（variant/fusion/backbone_2d/backbone_1d/task/predict_offset/triple_channel/use_coord_attn/staged_train/feature_len/seq_interp_mode/...），变更 → 重训 + 备份到 `checkpoints/backup/`。

**为什么需要**：保证"消融实验变量严格可控"——你改了某个参数，重训不会被旧检查点"污染"。

### 早停 patience = 30

**通俗版**：连续 30 个 epoch 验证集没提升就停。patience = "耐心"。

**技术解释**：连续 30 epoch val_loss 不改善 → 触发早停，节省算力 + 防过拟合。

### min_delta = 1e-4

**通俗版**：验证集损失要下降 **超过 1e-4** 才算"提升"。避免微小波动被误判为优化。

**技术解释**：val_loss < best_loss - 1e-4 才算改善；否则只是噪声。

### 14 任务设计（控制变量法）

**通俗版**：480 个理论组合 → 14 个精选。原则：
- **A 组**：5 个变体 baseline（每个代表一种范式）
- **B 组**：基于 A1 消融 5 个优化（单变量）
- **C 组**：组合 B 中有效的（验证协同）
- **A4_long**：DETR 150 epoch 长训（探索天花板）

**为什么不穷举**：8.5GB 单卡 8000+ GPU·小时 vs 实际 200 GPU·小时；边际收益递减；消融黄金法则。

## 四、常见追问预案（按"老师可能问什么"排序）

### Q："为什么选 ResNet-18 不选 ResNet-50？"
A：8.5GB 显存约束，ResNet-50 batch=4 都吃力；ResNet-18 跑 batch=8 留余量给其他模块。

### Q："Swin-Tiny 比 ViT-Small 强在哪？"
A：Swin-Tiny 用窗口注意力（O(N)）比 ViT 全局（O(N²)）省显存；多尺度 FPN 适合检测；shifted window 保留跨窗口信息。

### Q："DETR 为什么不直接出 100 个检测？"
A：100 个 query 是冗余候选 + Hungarian 匹配做最优分配；这是"端到端"的核心——不需要 NMS 后处理。

### Q："YOLO 网格 16×16 是怎么定的？"
A：`actual_grid_size = max(16, (image_size//32 // 4) * 4)`，动态计算，确保和 YOLO 头匹配。

### Q："CoordAtt 为什么是原创？SE 不行吗？"
A：SE 只编码通道维度，**丢位置**；CoordAtt 把 H/W 方向分开编码，**保留位置**，对裂纹定位任务更重要。

### Q："1e-3 真的会 NaN 吗？"
A：8-11 凌晨旧跑 epoch 18 NaN 验证过；DETR 是 Transformer，对 LR 极敏感。

### Q："分阶段训练为什么有效？"
A：课程学习思想——先学简单（短序列），再学难（长序列），降低初始学习难度，类似"先学 1+1 再学微积分"。

### Q："ThermalCutMix 和普通 CutMix 区别？"
A：普通 CutMix 混所有通道破坏应力场物理连续性；只混温度通道，保持物理合理性。

### Q："14 任务怎么不全做？"
A：480 个理论组合需 8000+ GPU·小时；14 任务 200 GPU·小时覆盖所有 6 个维度（每维度 100%）。
