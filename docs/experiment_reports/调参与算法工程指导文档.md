## 0. v5-α 损失函数（V5A3 + V5A5）

### 0.1 主损失：覆盖距离 + bbox + GP + 泊松

```
L_total = λ_cov · L_coverage
        + λ_bbox · L_bbox (Smooth L1)
        + λ_gp · L_gp (-log_marginal_likelihood)
        + λ_poisson · L_poisson
```

`OrderedKeypointLoss`（位于 `training/ordered_kp_loss.py`）：

| 损失分量 | 默认权重 | CLI 参数 | 说明 |
|----------|----------|----------|------|
| L_coverage | 1.0 | `--lambda_coverage` | B 样条 + Hausdorff/chamfer |
| L_bbox | 1.0 | `--lambda_bbox` | bbox Smooth L1 |
| L_gp | 0.1 | `--lambda_gp` | GP 超参数 LML（鼓励 ℓ/σ² 留在默认附近） |
| L_poisson | 0.05 | `--lambda_poisson` | 段长方差最小化（鼓励等弧长） |

**coverage_mode 参数**：
- `--coverage_mode chamfer`（默认，训练）：mean over true pixels of min distance
- `--coverage_mode hausdorff`（评估）：max over true pixels of min distance

**M 参数**（样条采样点数）：
- `--M 200`（默认）：200 个密集采样点覆盖曲线
- 减小可加速但损失精度降低

### 0.2 v5-α 训练循环调参

`run_train_v5.py` 关键参数（详见 [run_train_v5.py](../../run_train_v5.py)）：

| 参数 | 默认 | 范围 | 说明 |
|------|------|------|------|
| `--variant` | resnet18 | 5 变体 | 模型选择 |
| `--lr` | 1e-4 | 1e-5 ~ 1e-3 | Adam 学习率 |
| `--batch_size` | 4 | 1 ~ 32 | 受显存限制 |
| `--min_kpts` / `--max_kpts` | 8 / 16 | 4-20 | 关键点范围 |
| `--use_gp` | True | - | 启用 GP 嵌入模块 |
| `--pretrained_2d` | False | - | 启用 ImageNet 预训练 |
| `--crack_stress_threshold_MPa` | 50.0 | 5 ~ 200 | 裂纹萌生阈值 |
| `--fast_thermal` | False | - | 1 min 短热曲线（**仅测试**） |

### 0.3 v5-α 调参经验（待 V5A6 验证）

### 0.4 v5-α 故障排查

| 问题 | 原因 | 解决方案 |
|------|------|----------|
| 训练 loss = NaN | true_crack_pixels 全空 + 仿真未触发裂纹 | 降低 `--crack_stress_threshold_MPa` 或用 `--fast_thermal` |

| CSV 不写 | `log_dir` 路径无写权限 | 检查 `logs/` 目录是否存在 |

## 一、损失函数架构

PE-MMNet v4 有 5 种损失函数，根据任务和变体自动选择（`run_train.py:1462-1490`）：

### 1.1 基础模型（`resnet18` + 5 消融变体）

```
L_total = λ_mse · L_mse + λ_mono · L_mono + λ_loc · L_loc + λ_conf · L_conf
```

`MultimodalCrackLoss`：

| 损失分量 | 默认权重 | 说明 |
|----------|----------|------|
| L_mse | 1.0 | 密度 MSE 损失 |
| L_mono | 0.1 | 单调性约束 |
| L_loc | 1.0 | 定位损失（DIoU） |
| L_conf | 1.0 | 置信度损失（BCE） |

**`--lambda_mono`** 唯一暴露给 CLI 的损失权重。

### 1.2 YOLO 变体（`swin_yolo` / `vit_yolo` / `swin_yolo_patchtst`）

```
L_total = λ_box · L_box + λ_conf · L_conf + λ_mono · L_mono
```

`YOLOLoss`：

| 损失分量 | 默认权重 | 说明 |
|----------|----------|------|
| L_box | 1.0 | 边界框回归 |
| L_conf | 1.0 | 目标置信度 |
| L_mono | 0.1 | 单调性约束 |

`YOLOTargetAssigner` 负责网格分配：`grid_size=16, nearby_range=2`。

> ⚠️ **YOLO 变体的 lambda 是硬编码**，`--lambda_mono` 不生效（[CODE_BUGS.md B003](../CODE_BUGS.md)）。

### 1.3 DETR 变体（`detr`）

```
L_total = λ_bbox · L_bbox + λ_conf · L_conf + λ_mono · L_mono + 0.5 · L_supervise
```

`DETRLoss`：

| 损失分量 | 默认权重 | 说明 |
|----------|----------|------|
| L_bbox | 1.0 | Smooth L1 |
| L_conf | 1.0 | BCE |
| L_mono | 0.1 | 单调性 |
| L_supervise | 0.5 | 经 Hungarian 匹配后选出的最佳 query 经融合层输出的监督损失 |

`HungarianMatcher` 负责最优匹配（`cost_bbox=1.0, cost_density=1.0`）。

> ⚠️ **DETR 变体的 lambda 也是硬编码**。

### 1.4 分割任务（`task=segmentation`）

`SegmentationLoss`：

```
L = λ_dice · L_dice + λ_bce · L_bce
```

| 损失分量 | 默认权重 |
|----------|----------|
| λ_dice | 1.0 |
| λ_bce | 0.5 |

### 1.5 多任务（`task=multitask`）

`MultimodalSegmentationLoss`：

```
L = λ_seg · L_seg + λ_det · L_det
```

| 损失分量 | 默认权重 |
|----------|----------|
| λ_seg | 1.0 |
| λ_det | 0.5 |

## 二、各损失详解

### L_mse —— 密度预测损失

直接优化裂纹密度预测精度（仅 resnet18 变体）。

```bash
# 密度预测不准 → 增大
python run_train.py --lambda_mono 2.0  # 注意：CLI 实际是 lambda_mono，参见 [CODE_BUGS.md B003]
```

> 注：`--lambda_mse` 不是 CLI flag；`MultimodalCrackLoss.lambda_mse_density` 是构造时硬编码 1.0。如需调整，编辑 `run_train.py:1454`。

### L_mono —— 单调性约束

保证物理自洽性（裂纹不可逆）。**所有变体都有该损失**。

```python
L_mono = Σ max(0, pred[i+1] - pred[i]) / (n-1)
```

仅当密度下降时计算惩罚。

**CLI 调整**（仅对 6 个旧变体生效）：

```bash
# 物理违反率高 → 增大
python run_train.py --lambda_mono 0.3
```

### L_loc —— 定位损失

DIoU Loss，优化边界框定位精度（仅 resnet18 变体）。

```python
from training.mono_loss import LocalizationLoss
loss = LocalizationLoss(lambda_diou=1.0, lambda_mse=0.5, use_ciou=False)
```

### L_conf —— 置信度损失

BCE Loss，优化裂纹存在概率预测。

### L_supervise（DETR 专属）

匈牙利匹配选出的最佳 query 经 query_proj(6→128) → fusion(128, 64) → output_head(192→6) 的输出与 ground truth 的 L1 损失。权重硬编码 0.5。

## 三、调参场景

| 场景 | 指标问题 | 调参建议 | 适用变体 |
|------|----------|----------|----------|
| 密度预测不准 | R² 低 | 改 `MultimodalCrackLoss.lambda_mse_density`（源码） | resnet18 |
| 物理违反率高 | > 60% | `--lambda_mono 0.3` | 仅 6 个旧变体 |
| 位置预测不准 | mIoU 低 | 改 `LocalizationLoss.lambda_diou` | resnet18 |
| YOLO 边界框差 | box mAP 低 | 改 `YOLOLoss.lambda_box`（源码） | YOLO 3 个 |
| DETR 匹配差 | cost 不收敛 | 改 `HungarianMatcher.cost_bbox` | detr |

**调参流程**：

1. 先用默认配置观察 baseline
2. 根据评估结果针对性调整
3. 微调示例：
   - ResNet18：`MultimodalCrackLoss(lambda_mse_density=1.5, lambda_mono=0.2, ...)`
   - YOLO：`YOLOLoss(lambda_box=1.5, lambda_mono=0.15)`（源码层）

## 四、学习率调参

`run_train.py` 统一默认 `lr=1e-4`（`--lr` 参数默认值）。

| 架构 | 默认学习率 | 说明 |
|------|------------|------|
| ResNet18 | 1e-3 | `get_arch_specific_config` 自动升至 1e-3 |
| ViT / Swin / DETR | 1e-4 | 架构自适应降至此值 |

> `get_arch_specific_config()`（`models/pe_tsnet_multimodal.py:1680`）：`vit_small` 或 `transformer`/`dlinear` 骨干时 `lr=min(lr, 1e-4)`，`dropout≥0.2`；`vit_small+transformer` 时 `dropout≥0.3`。

```bash
# 手动指定学习率（推荐用于所有精细网络）
python run_train.py --lr 1e-4

# 提高学习率（更快但可能不稳定）
python run_train.py --lr 5e-4
```

## 五、高级优化参数

### 5.1 坐标注意力（所有变体均支持）

> 注：旧文档曾说"仅支持 resnet18"，但代码已支持所有变体。`--use_coord_attn` 对 5 个新变体都生效。

```bash
python run_train.py --variant resnet18 --use_coord_attn
python run_train.py --variant swin_yolo --use_coord_attn
python run_train.py --variant detr --use_coord_attn
```

### 5.2 分阶段训练

先短序列预训练，再长序列微调。

```bash
python run_train.py --variant resnet18 --staged_train --epochs 150
# 自定义短序列批次
python run_train.py --variant resnet18 --staged_train --short_batches 单次扫描 参数化扫描1
```

### 5.3 三通道时序输入

使用 `[初始温度, 当前温度, 温度变化率]` 三通道。

```bash
python run_train.py --variant resnet18 --triple_channel
```

### 5.4 ThermalCutMix

物理安全增强（仅混合温度通道，应力通道保持不变）。

```bash
python run_train.py --aug_cutmix_prob 0.3
```

### 5.5 密度一致性损失

邻域网格密度平滑约束，结合 MSE 密度损失和一致性损失。

```python
from training.mono_loss import CombinedDensityLoss

criterion = CombinedDensityLoss(
    lambda_mse=1.0,           # MSE 密度损失权重
    lambda_consistency=0.5,   # 一致性损失权重
    grid_size=16,             # 网格大小
    neighbor_range=1,         # 邻域范围
)
```

## 七、常见问题

| 问题 | 解决方案 |
|------|----------|
| Loss 是 NaN | `--lr 1e-4`（默认） |
| 违反率高 | `--lambda_mono 0.3`（仅旧变体） |
| 密度预测偏低 | 编辑 `MultimodalCrackLoss.lambda_mse_density` 源码 |
| 显存不足 | `--image_size 256 --batch_size 4` |
| 4 个新变体 `--lambda_mono` 无效 | 硬编码（[CODE_BUGS.md B003](../CODE_BUGS.md)） |
